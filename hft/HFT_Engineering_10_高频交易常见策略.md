# HFT Engineering从入门到入土（10）经典高频交易策略

笔者写这个系列，是把自己学习高频交易的过程记下来。前九篇回答的是“一笔交易怎样又快又稳地送到交易所”：订单协议、本地盘口、时钟、网络、C++、部署、回测，都属于工程。本篇换一个方向：这些工程能力到底服务于哪些交易思路？每一类策略的利润从哪里来，靠什么信号入场，延迟价值落在哪个环节，又主要承担什么风险。

本篇讲传统市场（股票、期货、ETF、外汇）和加密市场里常见的高频策略：期现与跨期套利、做市、统计套利、延迟与领先—滞后、订单流信号、集合竞价、执行算法，以及加密市场的资金费、跨所、AMM、MEV。

全篇中提到的每个策略按“利润从哪来 → 怎么算 → 算个例子 → 真做起来卡在哪 → 什么时候会亏”的顺序展开

## 读这篇需要知道的几个概念

下面这张表只给一句话解释，细节在正文首次出现的地方展开。

| 术语 | 一句话解释 |
|---|---|
| 基差 | 期货价格减现货价格（有时反向定义），到期时应收敛到零或交割结算价 |
| 持有成本 | 持有现货到交割所需的融资利息，减去收到的股息或便利收益，是理论期货价的基础 |
| 逐日盯市（mark-to-market） | 清算所每个周期按结算价重估持仓，浮动盈亏当日以现金划转，亏损当日要追加保证金 |
| 隐含价差 | 由两条腿的可成交价反推出的组合价差（如跨期两条腿、期权四腿），用于判断原生组合是否便宜 |
| maker / taker | maker 是先挂单等待成交、提供流动性的一方；taker 是立即吃掉已有挂单、消耗流动性的一方 |
| 返佣 | 交易所按成交股数给 maker 的报酬（maker-taker 结构），有时 taker 也领（inverted 结构） |
| 库存 | 做市商自己持有的净多或净空头寸，价格继续变动就会产生损益，需要主动回归中性 |
| 逆向选择 | 自己挂的单恰好被掌握信息的对手方吃掉，结果总是接到坏价格 |
| microprice | 用买卖价和各自挂单量加权出的“公允中间价”，比简单中点更接近下一成交方向 |
| 队列位置 | 自己的挂单在某个价位排队中的顺位，决定价格走到该档时自己排第几成交 |
| OFI | 订单流不平衡：一个窗口内新挂单减撤单减被成交的净方向数量，用来解释下一小段价格变动 |
| IOPV | ETF 的实时参考净值，用成份股实时价格估算，二级市场报价相对它的折溢价是 ETF 套利的信号 |
| AP | 授权参与商，有资格用一篮子成份股向基金公司申购 ETF 份额或把份额赎回成篮子的机构 |
| 协整 / OU | 协整指两个价格序列本身不平稳、但它们的线性组合平稳（围绕均值摆动）；OU 过程是描述这种均值回归的连续模型 |
| Delta / Gamma / Vega | Delta 是期权价对标的价格的敏感度；Gamma 是 Delta 自身的变化率；Vega 是对隐含波动率的敏感度 |
| 资金费率（funding） | 永续合约没有到期，多空之间定期互付的一笔费用，用于把合约价锚回现货指数 |
| 标记价格（mark price） | 交易所为结算盈亏与强平而用多来源指数算的公允价，不一定等于盘口最新成交价 |
| ADL | 自动减仓：极端行情下强平单无法成交时，按保证金效率排序自动对冲掉盈利对手方的仓位 |
| AMM | 自动做市商：链上用常数乘积等公式而非订单簿报价的 DEX 流动性池 |
| LVR | 损失 vs 再平衡：AMM 流动性提供者在价格不利方向被换掉的机会成本，被动做市相对被动盯市组合的系统性损耗 |
| MEV | 最大可提取价值：在区块内重排、插入、抢跑交易所能额外拿到的利润（传统市场的抢跑在链上的对应物） |
| PBS | 提议者—建造者分离：把区块内容的打包权与提议权分开，MEV 竞争与分发的一种架构 |
| 排序器（sequencer） | 链下/层二负责对用户交易排序并提交上链的组件，其排序规则决定 MEV 归属 |

## 1. 策略地图与本文阅读方法

![高频交易常见策略分类地图](https://raw.githubusercontent.com/Obscurepawn/TradingSystemLearning/main/hft/assets/hft-10/fig01_strategy_taxonomy.png)

*图 1：高频交易常见策略分类地图。*

先把问题摊开。假设你已经能把行情接到本地、在毫秒内算出一个数字、把订单送进交易所，然后呢？钱从哪里进来？不同策略的答案其实只有三类，区别只在“你凭什么赚到这一段价差”。

第一类是**收敛/回归类**：两个价格之间存在一条由成本、机制或统计关系决定的“合理位置”，现在它们偏离了，你买便宜的一边、卖贵的一边，等关系恢复就平仓。期现套利、跨期套利、ETF 套利、统计配对、外汇三角都属于这一类，赚的是“偏离被抹平”的钱，理论上不赌大盘方向。

第二类是**提供流动性类（做市）**：你不靠预测方向，而是在公允价两侧同时挂买单和卖单，谁来成交你都赚一个买卖价差，再加上交易所给 maker 的返佣；代价是要管理自己越积越多的库存，以及总被信息更足的人接到坏价格（逆向选择）。库存做市、期权做市是代表。

第三类是**速度/信息类**：公开信息已经变化、市场价格还没调完，你抢先一步成交。延迟套利、领先—滞后、订单流不平衡预测、新闻驱动都在这一类，拼的是在机会消失前赶到。

读每一个策略时，笔者建议对着三个问题判断：利润是“等价差收敛”“捕获一段价差”还是“先到先得”？机会能活多久，秒级、毫秒级还是微秒级？自己承担的主要是方向敞口、库存波动还是逆向选择？第 10 章把全部策略放进同一张对比表，第 11 章把每个策略的工程要求映射回本系列各篇。

监管口径上，美国 SEC 交易与市场部 2014 年的市场结构文献综述不给 HFT 下单一精确定义，而是沿用更早的概念文件，把短期交易策略分成四类：被动做市（非可成交挂单提供流动性，赚价差并常辅以返佣，利润不依赖方向）、套利（相关产品或市场之间的价差收敛，比如 ETP 与成份篮子）、结构性（利用市场或参与者的结构性脆弱，比如低延迟者对陈旧价格成交）、方向性（持仓赌涨跌，概念文件点名 order anticipation 与 momentum ignition 两类）[[137]][ref137]。这份综述同时提醒：只靠公开数据能算的代理变量——高消息速率、撤单突发、高报撤比、小单笔、速度提升——不足以识别 HFT，因为激进型、主动吃单的 HFT 占比超过一半，纯被动盘口指标会漏掉它们；在有账户标识的数据集中，识别 HFT 公司的经验因素包括净持仓日内穿越零的频率、订单存续时间、报撤/成交比 [[137]][ref137]。所以分类看利润来源，识别看行为维度，而不是只数每天下了多少笔单。

## 2. 期现套利

<a id="hft10-2-1"></a>
### 2.1 期货比现货贵了，能不能直接卖期货买篮子？

你看到沪深 300 股指期货比理论价贵了 8 个点，第一反应是“卖期货、买现货，等它回来”。这个方向感没错，但先别急着下单：期货凭什么应该等于现货？因为现金交割的期货在到期那天必须收敛到交割结算价，而现货指数在那一天也等于那个水平，两条价格曲线在终点被合约条款绑在一起。在此之前，期货价可以、而且应该偏离现货，偏离的大小由持有成本决定；只有偏离大到覆盖全部交易成本，这笔交易才有净利润。

具体有两种建仓方向。期货高于理论价时，卖期货、买现货篮子（或流动性好的 ETF），持有到收敛，这叫正向持有（cash-and-carry）；期货低于理论价时，买期货、卖空现货篮子，叫反向持有（reverse cash-and-carry），后者能不能做成，先看有没有券可借。

经典持有成本模型由 Cornell 与 French 在 1983 年系统讨论，他们同时指出税收时机选择权等摩擦会让实际期货价偏离纯持有成本模型的预测 [[1]][ref1]。基于中国沪深 300 股指期货 1 分钟高频数据的实证研究构建了无套利区间，发现正向（期货高估）套利机会显著多于反向（期货低估），原因在于现货难以卖空 [[2]][ref2]。

<a id="hft10-2-2"></a>
### 2.2 理论价怎么算：持有成本、分红与成本带

设现货指数为 $S$，无风险年利率 $r$，连续股息率 $q$，剩余期限 $T$（年），连续复利、连续股息率版本的理论期货价是：

$$F = S \, e^{(r-q)T}$$

$r>q$ 时期货理论升水，$q>r$ 时期货理论贴水。中金所科普文章给出对应的单利近似 $F=S[1+(r-y)\Delta t/360]$，其中 $y$ 为股息率，并明确升贴水由利率与股息率的相对大小决定，贴水本身不代表看空后市 [[3]][ref3]。

成分股在持有期内会分红。分红除权使现货指数自然回落，而期货持有者收不到分红，因此预期分红要先从现货里扣掉再计息。设确定分红 $D_i$ 发生在 $t_i$，离散分红版本为：

$$F = \left(S - \sum_i D_i e^{-r t_i}\right) e^{rT}$$

真实市场里没有“理想理论价可以直接成交”这回事。把全部往返成本——股票佣金、篮子买卖价差、冲击成本、期货手续费、融券利息、保证金占用的资金成本——折算成指数点 $c$，理论价两侧各扩一个成本带：

$$F_{\text{theory}} - c \le F_{\text{market}} \le F_{\text{theory}} + c$$

只有实际期货价穿出上沿（正向套利）或跌破下沿（反向套利）才有净利润。国内融券成本高、券源少时，下沿会被显著推高，区间下宽上窄，深度贴水仍可能落在“无利可图”的区间内 [[3]][ref3]。

保证金也是成本的一部分。期货只需缴纳合约价值一定比例的保证金（如沪深 300 股指期货最低交易保证金为合约价值的 8% [[4]][ref4]），但套利组合仍要为现货全额付款（或为空头准备融券），保证金占用的机会成本、逐日盯市的追加保证金压力都要计入 $c$。

这里有个容易被忽略的现金流错配。期货端实行每日按市值入账（mark-to-market）：清算所在每个清算周期按结算价重估未平仓头寸，浮动盈亏当日以现金划转——亏损日要立即追加现金，盈利日现金当日划入，以此消除债务累积；初始保证金才是押金，可以用现金或非现金抵押物缴纳 [[142]][ref142]。现货端（股票篮子或 ETF）的盈亏只有在卖出或平仓时才实现，持有期间只是账面浮动，不能当日取出。于是正向持有组合（买篮子、卖期货）会遇到这样的日子：期货空头在上涨当日就要付出现金，而篮子的账面浮盈不能当日动用；下跌日期货盈利现金到账，篮子浮亏同样没实现。错配不改变到期总盈亏，但要求账户预留独立于现货市值的现金缓冲应对追加，否则一笔账面盈利的组合也可能因为期货端短期亏损被强平。CME 股指基差页把理论价归为融资成本与股息的差额（fair value = 现货 + 融资 − 放弃的股息），和这里的持有成本模型一致 [[143]][ref143]。

### 2.3 算几个例子

第一个例子看连续复利下的正向持有和无套利区间（成本数字为教学假设，非市场实测）。

```text
设现货指数 S = 5000 点，无风险年利率 r = 5.0%，股息率 q = 2.0%，
剩余期限 T = 0.25 年（约 91 天）。

理论价：
  F = 5000 × e^{(0.05 − 0.02) × 0.25} = 5000 × e^{0.0075}
  e^{0.0075} ≈ 1.007528
  F ≈ 5037.64 点

往返成本 c = 30 点（股票佣金+篮子买卖价差+冲击成本+期货手续费折算，假设值）：
  无套利区间 = [5037.64 − 30, 5037.64 + 30] = [5007.64, 5067.64]

实际期货 F_market = 5075 点，高于上沿 5067.64：
  毛利 = 5075 − 5037.64 = 37.36 点
  净利 = 37.36 − 30 = 7.36 点
若合约乘数为每点 50 美元（CME E-mini S&P 500 规格 [[5]][ref5]）：
  每张净利 ≈ 7.36 × 50 ≈ 368 美元（未计融资与冲击误差）。
```

第二个例子看漏掉分红会错到哪里（数字为教学假设）。

```text
S = 4000 点，r = 4%（连续复利），T = 0.5 年；
t1 = 0.25 年时有一笔确定分红 D = 20 点（已折算到指数）。

分红现值：
  PV(D) = 20 × e^{−0.04 × 0.25} = 20 × e^{−0.01} ≈ 20 × 0.99005 = 19.80

理论期货价：
  F = (4000 − 19.80) × e^{0.04 × 0.5}
    = 3980.20 × e^{0.02} ≈ 3980.20 × 1.020201 ≈ 4060.60 点

若忽略这笔分红直接用 F = 4000·e^{0.02} ≈ 4080.81，
会把理论价高估约 20.2 点（分红现值及其利息），误判套利方向。
```

第三个例子就是前面说的盯市错配（教学假设）。

```text
正向持有组合卖出 1 张 E-mini S&P 500（乘数 50 美元/点 [[5]][ref5]），
开仓 F0 = 5000 点，持有同期现货篮子。

情形 A：当日结算价上涨 100 点至 5100。
  期货空头当日盯市亏损 = 100 × 50 = 5000 美元，当日以现金划出（变动保证金）；
  同期现货篮子账面浮盈 5000 美元，但未卖出、不可当日提取用于补保证金。

情形 B：当日结算价下跌 100 点至 4900。
  期货空头当日盯市盈利 = 100 × 50 = 5000 美元，当日以现金划入；
  现货篮子账面浮亏 5000 美元，未实现。

要点：期货端每日现金收付、现货端到期/平仓才实现，
账户需为情形 A 单独预留现金缓冲，不能用现货账面浮盈垫付当日追加。
```

最后给一个加密市场的对照（详细机制见第 8 章）：永续合约没有到期日，不靠强制收敛，而是靠资金费率把价格拉回现货指数。

```text
永续合约相对现货溢价，资金费率 f = 0.03%/8 小时；
买入现货、卖出永续，名义价值 100,000 美元。
每 8 小时收取资金费 = 100000 × 0.0003 = 30 美元；
每天 3 期 = 90 美元；毛年化 ≈ 90 × 365 / 100000 = 32.85%。
注意：永续没有到期日，不保证向现货收敛，收益是持续的资金费流
而非到期强制收敛；上述数字未扣买卖价差、资金成本、基差回归与强平风险。
资金费每 8 小时在 00:00、08:00、16:00 UTC 结算，多空互付、交易所不抽成 [[6]][ref6]。
```

<a id="hft10-2-4"></a>
### 2.4 入场前要看哪些信号

算理论价之前，先把这几项摆出来：理论价与实际价的偏差（mispricing）相对成本带的位置和宽度；融资利率 $r$、预期股息率 $q$ 与未来分红时间表（除权日、分红金额的预测误差）；剩余期限 $T$，临近到期基差趋零，偏离幅度通常随到期日临近缩小，高频实证中正向误定价平均约十余分钟回归 [[2]][ref2]；篮子可成交性，也就是成份股各档深度、买卖价差合计、组合抽样的跟踪误差；以及融券可得性与融券利率，这一项直接决定反向套利是否可行。

<a id="hft10-2-5"></a>
### 2.5 真做起来：篮子怎么下单，腿风险怎么管

正向套利要同时买入数十到数百只成份股，实践中要么用优化抽样的代表性篮子，要么用深流动性 ETF 替代。程序交易把母单拆成大量子单并发路由到各交易所；机构会预设成交比例门槛，篮子在目标价差内没能成交足够比例时，撤掉剩余单子并对冲已成交部分 [[7]][ref7]。用 ETF 当现货腿时，授权参与商（AP）可以用一篮子成份股申购 ETF 份额、再在二级市场卖出，这条申赎机制在 5.2 节展开。

两腿分别在不同市场成交，先成交的一腿立刻暴露于方向风险：期货先成交而股票篮子没齐，或者篮子成交后期货被别人抢走，都会留下净头寸。系统要实时跟踪两腿成交比例、剩余敞口与对冲状态，单边裸露的时间越短，价格风险窗口越小。对冲比例按名义价值匹配：期货张数 $N = V_{\text{basket}} / (m \cdot F)$，其中 $m$ 为合约乘数；组合有 beta 时再乘以组合 beta 做风险调整。

延迟敏感点集中在三处：理论价与区间的信号计算、篮子并发路由、两腿确认回报的闭环时间。偏差消失速度以分钟甚至秒计，抢不到队列或撤单过晚都会把毛利吃掉。

还有一个容易想当然的地方：持有到交割不等于“按盘中价收敛”。CME E-mini S&P 500 的最终结算用特别开盘报价（SOQ），以 500 只成份股各自第一个交易价格由指数供应商计算，在季度合约月第三个周五公布；每日结算价则取当日最后 30 秒 VWAP [[8]][ref8]。国内沪深 300 股指期货交割结算价为最后交易日标的指数最后 2 小时的算术平均价 [[4]][ref4]。用平均价或开盘价结算，意味着持仓要承受结算窗口内的路径波动，不能简单假设按收盘或盘中任意价平仓。

<a id="hft10-2-6"></a>
### 2.6 什么时候会亏

把可能的失败列一遍：分红预测错误、成份股调整、突发公司行动使理论价漂移；篮子流动性在波动中消失（闪崩场景），期货仍可成交而股票腿补不齐；融券被召回、券源收紧，反向套利建仓后无法维持；保证金追加、涨跌停板锁住一腿，无法平仓或展期；成本带估计过窄，冲击成本、印花税、融资利率被低估，表面套利实为亏损；结算窗口（SOQ、最后 2 小时均价）内还有操纵与异常波动风险。

<a id="hft10-2-7"></a>
### 2.7 不同市场的差别

美国股指这边，CME E-mini S&P 500（ES）合约规模为 50 美元 × 标普 500 指数，现金结算，季度合约（3/6/9/12 月），第三个周五交易终止 [[5]][ref5]；股票融券渠道成熟，正反向套利理论上都可行，也可以用 SPY 等 ETF 作为现货腿。

中国股指期货这边，沪深 300（IF）合约乘数 300 元/点，中证 500（IC）乘数 200 元/点，均现金交割、第三个周五到期、最低保证金 8% [[4]][ref4][[9]][ref9]。融券券源少、费率高（2013 年调研年化 8.6%–11.6%）、规模小，反向套利乏力，期货长期深度贴水且无法被套利纠正，这是官方对持续贴水的公开解释 [[3]][ref3]；高频实证也显示下沿突破仅占 0.2% 而正向偏离占 36.2% [[2]][ref2]。

加密市场只作对照：永续无到期，靠资金费率把价格拉回现货指数，不存在强制收敛，公式与约束细节在第 8 章展开。
<a id="hft10-3"></a>
## 3. 跨期套利

<a id="hft10-3-1"></a>
### 3.1 不赌方向，只赚两条腿价差的变化

假设你同时看到 12 月玉米报 5.00、3 月玉米报 5.16。你不想判断玉米接下来涨跌，只想赌这 0.16 美元的差价往哪走：买入一个月份的合约、卖出同一品种另一个月份同等数量的合约，两腿方向相反，这就是跨期套利，赚的是两条期货价格之差（日历价差）扩大或缩小的钱，而不是大盘涨跌的钱 [[10]][ref10]。买近月、卖远月叫牛市价差，反过来卖近买远叫熊市价差；蝶式套利则是两个共享中间月份的跨期组合拼在一起。

两条腿之间的合理距离，金融期货和商品期货不是一回事。股指、利率这类金融期货，两腿价差主要由持有成本差（利率减股息率，再乘以时间）决定；商品期货的价差还要叠加仓储费、保险费、资金利息这些持有成本，以及便利收益（持有现货本身带来的灵活度）。供应充足时远月比近月贵，叫 contango，价差刚好覆盖仓储；供应紧张时近月反而高于远月，叫 backwardation（倒挂），市场等于在"反向收取"仓储费 [[11]][ref11]。

这里要先拆掉一个常见误解。期现套利的两腿在同一到期日收敛到同一个交割结算价，基差有"到期归零"的硬条件；跨期套利两条腿到期日不同（$T_1\ne T_2$），到期时各自收敛到各自的现货或结算价，价差本身并不归零，市场不会在某个时刻强制把两条腿的价格拉平，认为价差"到期自动回归零"是错误类比。CME 对跨期（日历）价差的定义只是"同月品种、不同月份的反向两腿"，交易员盯的是两腿价格之差怎么变，多数情况下一边盈利、另一边亏损，靠盈利覆盖亏损，而不是等价差自己归到零 [[141]][ref141]。

价差真正有硬约束的，只有能通过实物储存、走交割路径复制的那一类（典型是商品）。这时完全持有成本（仓储、保险、资金利息，扣除便利收益）给出价差的上下界，超出边界会触发存储套利把价差压回去，CME 谷物教育页干脆把日历价差描述成"市场对储存的出价"：供应充足时价差拉大，鼓励人把货存起来；短缺时价差缩小甚至倒挂 [[141]][ref141]。其余情形——股指跨期、利率合约跨期，以及一切没有实物储存和交割复制路径的关系——都属于统计相对价值：价差围绕持有成本差（金融期货为 $(r-q)\Delta T$）、历史均值或季节形态波动，回归靠市场套利力量推，不靠合约条款强制，可能长期不回归，甚至单向扩大。

<a id="hft10-3-2"></a>
### 3.2 合理价差怎么算

金融期货的合理价差，直接把持有成本模型写两次、两式相减：

$$F_{T_2} - F_{T_1} \approx S\,(r-q)\,(T_2 - T_1)$$

合理价差随时间差线性展开，偏离合理价差、并预期回归时进场。

商品期货要看完全持有（full carry），也就是把货存到远月到期的全部成本摊进价差：

$$F_{\text{远}} - F_{\text{近}} = u\,(T_2-T_1) + r\,P\,(T_2-T_1) - y_c$$

其中 $u$ 是单位时间仓储/保险费，$rP\Delta T$ 是占用资金的利息，$y_c$ 是便利收益。远月升水超过完全持有上限时，存储套利（买近卖远、实物交割入库）会把价差压回；倒挂时则没有人愿意储存 [[11]][ref11]。农产品还有种植、收获的季节性，新老作年度价差有规律的季节形态。

先看一个商品完全持有的例子（仓储/利息数字为教学假设，CME 一张玉米合约 5000 蒲式耳）。

```text
示例 1（仓储/利息数字为教学假设）：商品完全持有价差（玉米，CME 一张合约 5000 蒲式耳）。
12 月玉米 F_Dec = 5.00 美元/蒲式耳，3 月玉米 F_Mar = 5.16 美元/蒲式耳。
3 个月完全持有成本：仓储 0.12 美元 + 利息 5.00 × 6.4% × 3/12 ≈ 0.08 美元
  = 0.20 美元/蒲式耳。
市场实际远−近价差 = 5.16 − 5.00 = 0.16 美元，低于完全持有 0.20，
即远月升水不足以覆盖仓储，预期价差向 0.20 回归。
操作：买 12 月、卖 3 月（买近卖远）各 1 张。
价差从 0.16 走到 0.20 平仓：
  毛利 = (0.20 − 0.16) × 5000 蒲式耳/张 = 0.04 × 5000 = 200 美元/张。
```

第二个例子用国内官方组合指令的规则数值，看平仓盈亏怎么算（郑商所价差约定为近月价减远月价）。

```text
示例 2（官方规则数值）：国内组合指令的平仓盈亏（郑商所价差约定：价差 = 近月价 − 远月价）。
建仓：组合买单 B CF509/CF511，成交价差 −990（买近 15010、卖远 16000）。
平仓：组合卖单 S CF509/CF511，成交价差 −220。
按郑商所官方公式：平仓盈亏 = (卖单价差 − 买单价差) × 合约单位 × 张数
  = [−220 − (−990)] × 5 吨/张 × 1 张
  = 770 × 5 = 3850 元。
```

### 3.3 真做起来：看什么信号，怎么下单

入场前先把几项摆出来：当前价差相对理论完全持有价、历史均值或季节形态偏离多少；远近月各自的流动性、持仓量、买卖价差与队列深度；商品还要看仓储容量与仓单成本、利率水平、作物年度与季节性；最后是价差的最小变动价位和保证金优惠比例。

境外市场这边，CME 为主要日历价差维护独立的价差簿，原生价差簿与隐含报价是执行的两条路径。原生价差单作为一笔交易原子成交，不承担腿风险；价差簿深度不足时，撮合引擎用两腿直接订单合成报价（implied in），或用价差单加一条腿合成另一条腿的直接报价（implied out，即由已有组合报价反推出单腿价格）[[12]][ref12][[13]][ref13]。E-mini S&P 500 的日历价差最小变动为 0.05 个指数点（2.5 美元），小于直接合约的 0.25 点 [[5]][ref5]。要注意隐含报价不是真实挂单：直接腿成交、撤单都会实时改变隐含价差，看到的"深度"会波动；CME 对隐含报价按整档 tick 取整（买向下取整、卖向上取整）[[13]][ref13]。

国内交易所提供官方套利/组合指令。大商所提供同品种跨期套利指令：买入近月、卖出同等数量远月，套利报价等于近月申报价减远月申报价，撮合系统按规定比例同时成交 [[14]][ref14]；盘中可经套利订单实时享受组合保证金优惠（两腿合并后只按保证金要求更高的一条腿单边收取），期货跨期按高腿单边收取保证金 [[15]][ref15]。郑商所跨期套利组合指令只报价差、不报两腿价格，按"价差优先、时间优先、远近月同时成交且数量相等"撮合；组合买单要求买单价差 ≥ 近月最优卖价 − 远月最优买价，组合卖单反之 [[16]][ref16]。上期所套利（跨期/跨品种）需申请套利交易持仓额度以扩大限仓，交易所可另行制定套利保证金与手续费办法 [[17]][ref17]。

原生价差单只成交了一部分，余量怎么办。CME Globex 的默认限价原生价差单若只成交一部分，未成交余量留在价差簿内继续排队，直到成交或被撤销；FAK（Fill and Kill）立即按可成交量成交、余量撤销，FOK（Fill or Kill）不能立即足额成交则整单撤销，最小数量（Minimum Quantity）不足也整单取消 [[150]][ref150]。国内一般交易指令未一次全部成交且未撤销的，余量仍存于系统继续参加当日竞价，"交易所另有规定的除外" [[144]][ref144]；而官方套利/组合指令走特殊规则——大商所套利指令由撮合系统按规定比例同时成交 [[14]][ref14]，郑商所组合指令保证两合约同时成交且数量相等，且套利指令不参与集合竞价、行情单方无报价时不得下达 [[16]][ref16][[145]][ref145]，制度上不留下单腿余量。反过来，若不走官方组合指令而自行两腿下单，任何一单只成交一部分，已成交腿立即形成裸方向敞口，系统必须在"撤掉已成交腿对冲"和"继续挂单补齐"之间做选择，不能默认剩余会自动成交。

原生价差与两腿单独下单怎么选。走原生价差或组合指令，没有腿风险、还享保证金优惠，但要在价差簿排队，成交依赖对手方或隐含流动性，抢的是价差队列位置与报价更新速度。两腿单独下单可以选到更优的两腿价格，但承担单边成交风险；做市报价时需要预先指定一条"参考腿"锚定价差，另一条腿跟随执行，研究用订单流 Hawkes 预测与即时订单簿流动性因子来选择哪条腿更稳，以缩短首腿成交到双腿完成之间的执行风险窗口 [[18]][ref18]。延迟敏感点集中在：价差行情重建、隐含报价剔除与纳入、两腿成交回报配对、单边敞口的立即对冲或撤单。

<a id="hft10-3-6"></a>
### 3.4 什么时候会亏，以及不同市场的差别

失败按机制归拢一下：一腿成交、另一腿没成交，组合变成裸方向头寸（legging risk）；完全持有估算错误，仓储费、利率、仓单容量变化让"合理价差"漂移；季节性或供需预期反转，价差不回归反而继续扩大（逼仓：空头被挤到高位被迫平仓，叠加库存紧张）；临近交割月流动性转移、移仓换月导致价差跳变；涨跌停板或交易中断锁住一腿，组合保证金优惠资格被取消时还要追加保证金；依赖隐含流动性时，直接腿撤单会让合成报价瞬间消失。

市场环境上，CME 等境外市场把原生价差合约、隐含 in/out、组合保证金冲销做成标准基础设施 [[5]][ref5][[12]][ref12][[13]][ref13]。国内商品期货这边，大商所、郑商所有官方套利指令与盘中/盘后组合保证金优惠 [[14]][ref14][[15]][ref15][[16]][ref16]，上期所采用额度申请制 [[17]][ref17]，中金所股指期货的跨期按其套保/套利管理规定执行。红线提醒一句：不得利用套利额度或价差报价操纵市场、不得幌骗挂单，具体边界见第 7 章。

<a id="hft10-4"></a>
## 4. 做市算法

想象你站在盘口两边同时报价：愿意按买一买、也愿意按卖一卖，谁来成交你都落一段买卖价差。这件事的麻烦不在报价本身，而在成交之后——你手里会攒下净多或净空的头寸（库存），价格继续走就会产生损益；更糟的是，你的挂单常常恰好被知道消息的人吃掉（逆向选择，也就是自己挂的单总在对方向自己有利时成交）。这一章把库存风险、逆向选择、公允价估计、排队与撤单竞争、期权做市和交易所返佣制度拆开讲。

<a id="hft10-4-1"></a>
### 4.1 库存压在身上时，报价该怎么偏：Avellaneda–Stoikov 模型

你手里已经多头 2 个单位，价格却还在往下走。此时两边继续对称报价，等于在亏损方向上加码。Avellaneda–Stoikov（下称 A-S）模型回答的就是这个问题：既然持有库存有风险，报价应该围绕什么价格偏、偏多少。

钱从哪里来，又为什么有人把这段钱让给你？做市商围绕一个估计的合理价格（中间价 $s$）同时挂买单和卖单，两边先后成交时赚取买卖价差；代价是库存暴露在价格波动下，价差收入必须补偿这段库存风险。A-S 用指数效用把“厌恶库存风险”量化为风险厌恶系数 $\gamma$，先求一个和自己库存挂钩的主观保留价（reservation price，库存调整后的估值），再结合订单成交强度决定报价距离 [[19]][ref19]。

先看价格怎么动。中间价 $S_t$ 服从带漂移（可设为零）的布朗运动：$dS_t=\sigma dW_t$。

报价离中间价越远，被动单被市场单（taker 立即吃掉挂单的一方）成交的概率越低，A-S 把成交强度写成指数形式。报价距离中间价 $\delta$ 时，泊松到达强度为：

$$\lambda(\delta)=A\,e^{-k\delta}$$

$A$ 是距离为零时的基准到达强度，$k$ 是强度对距离的衰减率；距离越远，成交越稀。这个指数形式来自市场单规模的幂律分布与对数价格冲击 [[19]][ref19]。

关键是保留价。无交易冻结库存情形下：

$$r(s,q,t)=s-q\,\gamma\sigma^2(T-t)$$

$q$ 为当前库存（多头为正）。$q>0$ 时 $r<s$，主观估值低于中间价，倾向于卖出去库存；$q<0$ 时 $r>s$，愿意以更高价格买回 [[19]][ref19]。

最优总价差（线性近似闭式解）：

$$\delta^a+\delta^b=\gamma\sigma^2(T-t)+\frac{2}{\gamma}\ln\!\left(1+\frac{\gamma}{k}\right)$$

第一项是库存风险补偿，随剩余时间 $T-t$ 与波动率增大；第二项是成交强度（流动性）补偿。总价差和库存 $q$ 无关，库存只通过保留价把整体报价偏移（skew）。最优报价为：

$$p^b=r-\frac{\delta^a+\delta^b}{2},\qquad p^a=r+\frac{\delta^a+\delta^b}{2}$$

先看一个例子。

```text
示例（A-S，参数为自设示例，非市场实测）：
中间价 s=100.00，风险厌恶 γ=0.1，波动率 σ=2.0（单位价格/√时间），
剩余时间 T-t=1.0，当前库存 q=2（多头 2 单位），衰减率 k=1.5，基准强度 A=1。

第 1 步：保留价
r = s - q·γ·σ²·(T-t)
  = 100.00 - 2 × 0.1 × 2² × 1.0
  = 100.00 - 0.80 = 99.20

第 2 步：最优总价差
风险项 = γσ²(T-t) = 0.1 × 4 × 1.0 = 0.40
流动性项 = (2/γ)·ln(1+γ/k) = 20 × ln(1+0.1/1.5)
         = 20 × ln(1.06667) ≈ 20 × 0.06454 = 1.2908
总价差 = 0.40 + 1.2908 = 1.6908，半价差 = 0.8454

第 3 步：最优报价
p^b = 99.20 - 0.8454 = 98.3546
p^a = 99.20 + 0.8454 = 100.0454
买单距离 δ^b = 100.00 - 98.3546 = 1.6454
卖单距离 δ^a = 100.0454 - 100.00 = 0.0454

第 4 步：对应成交强度（A=1）
λ^b = e^(-kδ^b) = e^(-1.5×1.6454) = e^(-2.4681) ≈ 0.0847
λ^a = e^(-kδ^a) = e^(-1.5×0.0454) = e^(-0.0681) ≈ 0.9342

对照 q=0：r=100.00，p^b=99.1546，p^a=100.8454，两边对称。
```

多头 2 单位时，卖单几乎贴在中间价上（强度 0.93，容易成交、主动减库存），买单被压到很远（强度 0.085，尽量不再买）。偏移方向由库存决定，价差宽度由风险与流动性决定。

*图 4：中间价、保留价与最优买卖报价；库存为正时整体报价向下偏移，卖单更近、买单更远。*

真做起来，几个参数要自己校准。$\gamma$ 是风险厌恶，越大越急于回归零库存、报价偏移越强，工程上常作为可调旋钮；$\sigma$ 是估计的短期波动率，波动放大时总价差扩大、偏移增强；$k$、$A$ 是成交强度参数，用历史市场单按距离分桶回归 $\ln\lambda=-k\delta+\ln A$ 校准 [[20]][ref20]。$T-t$ 是有限期限项，越接近到期库存风险定价越低，盘中连续做市时这个设定并不自然，这也是 4.2 节 GLFT 渐近（无期限）版本的由来。

报价要随库存 $q$、实时 $\sigma$ 连续重算并改单。库存只能从自己的成交回报累加，公开行情里看不到你已经买了多少。改单、撤单要赶在旧报价被不利成交之前生效，竞争对象是抢单方的成交消息，这条在 4.4 节展开。成交强度校准用滑动窗口的市场单到达记录，$A$、$k$、$\sigma$ 定期重估；hftbacktest 示例每 5 秒更新、10 分钟窗口 [[20]][ref20]。

什么时候会亏？指数强度假设在大跳价、事件窗口失真；参数滞后会导致报价过宽（丢成交）或过窄（被扫）。模型只处理库存风险，不显式建模逆向选择；信息不对称强的时段，按 A-S 报价仍会系统性买在跌前、卖在涨前（见 4.3）。$\sigma$ 突增而模型没更新时，库存风险敞口被低估。

代入公式前还有两处使用注意。一是单位：价格取“一份固定交易单位的现金价格”，库存 $q$ 记为该单位的份数；$\sigma$ 是算术价格波动（价格/√时间），不是年化收益率波动率——时间用秒，$\sigma$ 单位就是价格/√秒，$A$ 为每秒强度，$k$、$\gamma$ 是价格的倒数，这样 $\gamma\sigma^2(T-t)$ 才具有价格单位。期货先把点数乘以合约乘数换成现金价格再代入，年化收益率波动率先换算成算术价格波动率；$T-t$ 与 $\sigma$ 必须用同一时间尺度，不可一个用秒、一个用年。二是模型边界：A-S 的闭式报价是 $t$ 接近 $T$ 时的 Taylor 展开，远离终端时间 $T$ 时最优报价几乎不依赖 $t$，长时间连续做市应使用 4.2 的渐近闭式解，不能把含 $(T-t)$ 的 A-S 闭式无限期外推；终端目标是期末剩余库存按参考价 $S_T$ 做 mark-to-market 估值，模型没有显式强制清仓成本，因此 $T-t$ 缩小不等于策略会自动清仓，实盘必须另设退出、对冲规则（4.4）[[19]][ref19][[21]][ref21]。

不同市场的差别：股票、期货、加密永续等连续撮合、价格—时间优先市场均可套用；有限期限 $T$ 对日内合约、到期前平仓的品种更自然。模型本身是合法做市，不得用于幌骗、分层等操纵（第 7 章）。

<a id="hft10-4-2"></a>
### 4.2 不设终点的版本：GLFT 渐近闭式解与库存上限

A-S 带着一个人为的终点 $T$，可你打算一整天甚至长期持续报价，终点在哪里？Guéant、Lehalle、Fernandez-Tapia（GLFT）沿用同样的布朗中间价与指数成交强度，但把有限期限的 HJB 方程转化为线性常微分方程组求解，给出无终端时间的渐近闭式近似。工程上最常用的是它的半价差（half spread）与库存偏移（skew）分解，外加显式的库存截断（hard capacity $\bar q$）[[21]][ref21]。

在 $\Delta=1$、$\xi=\gamma$（离散库存步长、风险厌恶）的常用简化下，先定义两个系数：

$$c_1=\frac{1}{\gamma}\ln\!\left(1+\frac{\gamma}{k}\right)$$

$$c_2=\sqrt{\frac{\gamma}{2Ak}\left(1+\frac{\gamma}{k}\right)^{k/\gamma+1}}$$

半价差与偏移为：

$$\text{half\_spread}=c_1+\frac{\sigma}{2}c_2,\qquad \text{skew}=\sigma c_2$$

保留价与报价：

$$r=\text{mid}-\text{skew}\cdot q$$

$$p^b=r-\text{half\_spread},\qquad p^a=r+\text{half\_spread}$$

即买单深度 = half_spread + skew·q，卖单深度 = half_spread − skew·q；$q>0$ 时卖单更近、买单更远 [[20]][ref20]。

库存上限是模型之外的硬约束。原模型在 HJB 中对 $q\in[-\bar q,\bar q]$ 加边界条件（超出区间不再报价或惩罚），闭式近似不显式给出硬限，工程上直接用 `max_position` 截断：买单仅在 $q<\bar q$ 时提交，卖单仅在 $q>-\bar q$ 时提交 [[21]][ref21][[20]][ref20]。

先看一个例子。

```text
示例（GLFT 渐近闭式，单位为 tick 与每步时间，参数为自设示例）：
γ=0.05，k=0.5，A=2.0，σ=0.2（tick/步），库存 q=3，中间价 mid=100（仅作显示）。

第 1 步：c1
c1 = (1/γ)·ln(1+γ/k) = 20·ln(1+0.05/0.5) = 20·ln(1.1) ≈ 20×0.09531 = 1.9062 tick

第 2 步：c2
底数 1+γ/k = 1.1，指数 k/γ+1 = 0.5/0.05+1 = 11
c2 = sqrt( γ/(2Ak) · 1.1^11 )
   = sqrt( 0.05/(2×2×0.5) × 1.1^11 )
1.1^11 ≈ 2.8531；0.05/2 = 0.025
   = sqrt(0.025 × 2.8531) = sqrt(0.07133) ≈ 0.2671

第 3 步：半价差与偏移
half_spread = c1 + (σ/2)·c2 = 1.9062 + 0.5×0.2×0.2671 ≈ 1.9329 tick
skew = σ·c2 = 0.2×0.2671 ≈ 0.0534 tick/单位库存

第 4 步：保留价与报价
r = mid - skew·q = 100 - 0.0534×3 = 99.8398
p^b = r - half_spread ≈ 97.9068（距中间价 2.0932 tick）
p^a = r + half_spread ≈ 101.7727（距中间价 1.7727 tick）

对照 q=0：r=100，买卖对称分布在 100±1.9329 tick。
```

$A,k$ 由市场单到达强度按距离分桶、$\ln\delta$ 线性回归校准；$c_1$ 只依赖流动性，$c_2$ 同时依赖强度与 $\gamma$。$\sigma$ 取滑动窗口中间价变动标准差。`max_position` 是模型之外的工程硬库存上限，达到后停止该方向报价。实际部署常给 half_spread、skew 乘调整系数，因为理论偏移过强会导致几乎不成交 [[20]][ref20]。

无到期时间，适合股票、现货、加密永续等持续做市；每 100ms 级周期重算并撤旧挂新。队列位置（自己在某个价位排队中的顺位）在标准教程中被简化忽略，精细实现需把成交概率与排队位置挂钩（4.4）[[20]][ref20]。参数拟合不好时，可用非参数强度（均值、中位数、分位数）替代指数形式，甚至只留波动率驱动的固定半价差 [[22]][ref22]。

什么时候会亏？指数强度假设在小 tick、长 tick 品种上拟合差；大 tick 品种应引入 microprice（用买卖价和各自挂单量加权出的公允中间价，比简单中点更接近下一成交方向）作为公允价修正 [[22]][ref22]。模型只含库存风险项，不含 alpha 信号与逆向选择调整，需在外层叠加（4.3）。

<a id="hft10-4-3"></a>
### 4.3 为什么总在坏价格成交：逆向选择与毒性开关

你有没有发现，自己一买单价格就往下走，一卖单价格就往上走？A-S/GLFT 只补偿库存风险，解释不了这件事。真正的另一类亏损来源是对手方拥有私人信息：被动买单总是在有人知道价格要跌时被成交。Glosten–Milgrom 证明，即使做市商风险中性、期望利润为零，只要存在知情交易者，价差依然为正——价差是给知情交易者亏损的补偿，由流动性交易者的成交赚回 [[23]][ref23]。Kyle 把信息融入价格的过程建模为知情交易者、噪声交易者与做市商的序贯博弈，用市场深度参数 $\lambda$ 刻画交易量对价格的冲击 [[24]][ref24]。

几个模型分支顺着这条线展开。

- Glosten–Milgrom：做市商按“下一笔是买单还是卖单”分别更新条件期望价值，报价满足 $A_t\ge E[V\mid \text{买入}]\ge B_t$，均衡中每笔交易期望利润为零；交易本身把信息带入价格 [[23]][ref23]。
- Kyle（1985）：线性均衡中知情交易者分批利用私人信息，做市商设定 $p=\mu+\lambda x$，$\lambda$ 越大市场越浅；内幕利润随深度与噪声交易量变化 [[24]][ref24]。
- Cartea–Jaimungal 一类扩展：把终端指数效用换成运行库存惩罚（running penalty）$\phi\sigma^2\int q_s^2 ds$，并可加入漂移信号 $\alpha$（方向观点）调整报价；论文证明对中间价漂移的模糊厌恶等价于施加运行库存惩罚，库存越大越贴近中间价挂单加速回归 [[25]][ref25][[26]][ref26]。
- VPIN（flow toxicity，流量毒性）：Easley、López de Prado、O'Hara 用成交量桶（volume bucket）内买卖量失衡比的均值度量毒性，毒性高时做市商应加宽价差或撤回报价；VPIN 在体积时钟上更新，不估计不可观测的 PIN 参数 [[27]][ref27]。

这一节是概念框架，不展开算例；VPIN 与惩罚项的参数标定属于实证研究。

成交方向失衡、大单冲击、订单流不平衡（一个窗口内新挂单减撤单减被成交的净方向数量，即 OFI）作为毒性、alpha 输入；惩罚系数 $\phi$ 控制库存回归速度，信号 $\alpha$ 使报价在无库存偏移之外再叠加方向倾斜 [[26]][ref26]；VPIN 水平作为“是否暂停做市、加宽”的开关量 [[27]][ref27]。

毒性上升时的动作是加宽、远离或撤单，而不是反向追单；这需要快速的成交分类（买、卖）与桶内累计。信号 $\alpha$ 与库存偏移叠加时，要避免把方向性观点伪装成做市导致裸头寸。

什么时候会亏？VPIN 与成交量、波动率机械相关，学界对其预测力存在争议（Andersen–Bondarenko 的批评），只能作辅助开关，不能单独定价。把 alpha 信号写进报价后，策略从“中性做市”滑向方向交易，业绩归因必须分开。

股票、期货、期权通用；内幕交易、抢信息属于违法，模型只使用公开订单流信息，不得利用未公开重大信息。

<a id="hft10-4-3b"></a>
### 4.3a 成交质量评估：markout 与 realized spread

双边报价到底赚不赚钱，不能只看成交流水或价差毛额，要逐笔问：这笔被动成交在那一刻拿到了多少价格优势，成交之后沿持仓方向价格是往有利还是不利方向走。后者正是逆向选择的逐笔度量口径，把 4.3 的毒性从开关量落到每一笔成交上。

令 $z=+1$ 表示买入、$z=-1$ 表示卖出，$t_f$ 为成交时刻，$p_f$ 为成交价，$m_{t_f^-}$ 为成交前一刻中间价，$m_{t_f+h}$ 为成交后经过 $h$ 的中间价。标记收益（markout）：

$$M_h=z\left(m_{t_f+h}-p_f\right)
=\underbrace{z\left(m_{t_f^-}-p_f\right)}_{\text{成交前价格优势}}
+\underbrace{z\left(m_{t_f+h}-m_{t_f^-}\right)}_{\text{持仓方向的后续价格变化}}$$

第一项是相对成交前盘口拿到的价格优势（成交得比当时中间价更好），第二项是成交前到评价时点沿持仓方向计的价格变化（信息、毒性代价）。中间价标记尚未扣除实际退出所付价差与费用。报价价值可粗写为：成交概率乘以（$M_h$ + 返佣 − 手续费 − 退出成本），再减去新增库存风险代价；若成交后的不利价格变化与其他成本更大，交易仍然亏损。

先看一个例子。

```text
示例：以 100.00 买入 1 单位；成交前一刻中间价 m_{t_f^-}=100.01；
成交后 h 时中间价 m_{t_f+h}=99.96。

第 1 步：成交前价格优势 = 1 × (100.01 − 100.00) = +0.01
第 2 步：持仓方向后续价格变化 = 1 × (99.96 − 100.01) = −0.05
第 3 步：标记收益 M_h = 1 × (99.96 − 100.00) = −0.04
校验：+0.01 + (−0.05) = −0.04
```

最初拿到 0.01 的价格优势，被随后 −0.05 的不利变化抵消，净标记 −0.04；这笔“看起来成交在买一”的单子事后是亏的。卖出方向对称：卖在更好价位得 +0.01 优势，随后价格上行则给出 −0.05 的毒性代价。

![markout 时间线](https://raw.githubusercontent.com/Obscurepawn/TradingSystemLearning/main/hft/assets/hft-10/fig10_markout_timeline.png)

*图 5：成交价相对成交前中间价的价格优势，与成交后沿持仓方向的后续价格变化，两段相加即 markout。*

评价跨度取 $h$，内部 markout 常用几秒到几分钟，可对多档 $h$ 分别统计，与监管 realized spread 的多时间跨度口径一致 [[132]][ref132]。按报价距离（$\delta$）、队列位置、品种、时段、毒性水平分层聚合；负 markout 集中在某一档，说明该档被毒性成交主导。返佣（交易所按成交给 maker 的报酬）、手续费、退出价差与滑点单独计入，不混入 $M_h$。

markout 依赖成交前一刻中间价（需保留 $t_f^-$ 快照）与未来 $h$ 的中间价，回测、实盘归因都要按笔对齐；SESSION 边界、集合竞价、断档需特殊处理。分层聚合的结果接回 4.3 的毒性开关，形成“哪档报价该加宽、远离”的反馈。

短 $h$ markout 噪声大，长 $h$ 混入对冲与仓位管理影响，需固定口径再比较策略；中间价标记不含退出成本，不能直接当作净 PnL，净 PnL 须扣往返费用与退出价差。SEC Rule 605 要求交易中心披露 realized spread，按成交后多个时间跨度（50 毫秒、1 秒、15 秒、1 分钟等）的中间价回看成交价并按成交股数加权 [[132]][ref132]；内部 markout 是同一思想的自定义版，用于报价优化而非监管报送。做市控制与“成交条件下的后续价格”分析见 Cartea–Jaimungal–Penalva 专著 [[25]][ref25]。

<a id="hft10-4-4"></a>
### 4.4 公允价估多少、排第几、撤单谁先到

实际做市算法在“风险价差 + 库存偏移”之外，还要解决三件事：用什么价格当公允价、队列位置值多少钱、信息出现后撤单与抢单谁先生效。

报价偏移（skew）把保留价从中间价平移，等价于按库存减小买入意愿、增强卖出意愿（4.1、4.2 公式）；工程上也常用归一化库存 $q/\bar q$ 线性缩放买卖深度 [[22]][ref22]。达到 `max_position` 停止单边报价；超限时主动用相关资产（标的期货、对冲篮子）反向对冲，把单边裸露的时间压到最短 [[28]][ref28]。

最简单的公允价修正是加权中间价（weighted mid），用对手挂单量加权：

$$p_{\mathrm{wm}}=\frac{P^a Q^b+P^b Q^a}{Q^b+Q^a}$$

```text
示例：买一 100.00/900 股，卖一 100.01/100 股。
p_wm = (100.01×900 + 100.00×100)/(900+100) = 100.009，
明显偏向卖方压力小的一侧（买盘厚，公允价靠上）。
```

Microprice（Stoikov 2018）不是静态量加权，而是把 $M+g(I,S)$ 构造为未来中间价期望的无穷极限、按鞅条件递归修正 $g(I,S)$（$I$ 为顶部失衡、$S$ 为价差），实证上对近期价格的预测优于中间价与加权中间价 [[29]][ref29]；BBO 级 microprice 对大 tick 品种有效、对小 tick 品种作用有限 [[22]][ref22]。

队列位置也值钱。价格—时间优先下，同一价位前排订单的成交概率与逆向选择成本都不同于后排；Moallemi–Yuan 把位置价值拆为静态项（赚价差 vs 承担逆向选择）与动态项（锁定队列位置的期权价值），实证中大 tick 股票的队列价值可与整个买卖价差同量级 [[30]][ref30]。Dahlström、Hagströmer、Nordén 用 OMXS30 的逐笔订单数据实证：队前量（Front of Queue Quantity）、队后量（Back of Queue Quantity）、对手深度与库存共同决定撤单概率，说明队列位置是撤单决策的输入而非静态常数 [[31]][ref31]。

信息跳变那一刻，撤单和抢单在赛跑。连续撮合串行处理消息，公共信息跳变后，做市商发撤单、$N-1$ 个抢单发旧价成交请求，旧报价被扫中的概率为 $(N-1)/N$；抢单租金诱发速度竞赛（囚徒困境），做市商把被扫成本计入报价使价差变宽。论文据此提出频繁批量拍卖作为市场设计回应 [[32]][ref32]。

![队列位置、撤单与抢单的竞争时序](https://raw.githubusercontent.com/Obscurepawn/TradingSystemLearning/main/hft/assets/hft-10/fig05_queue_position.png)

*图 6：同一信息跳变出发，撤单请求与抢单成交请求串行进入撮合引擎，先到者决定旧报价退出还是被扫。*

要看的信号有顶部失衡 $I=Q^b/(Q^b+Q^a)$、价差 $S$、队前/队后量、自身队列位置（MBO 逐笔订单事件流里能定位自己的订单），外加库存归一化水平、对冲腿的 Beta/乘数、毒性开关（4.3）。

队列位置估计依赖 MBO 或自身回报推断；GTX（不跨价差）订单常用于避免被动单意外穿越 [[20]][ref20]。信息事件一到，撤单链路越短越好；sniping 竞争中失败的抢单以 IOC 立即撤回 [[32]][ref32]。对冲腿独立成交，可能只成一边，留下临时敞口。

什么时候会亏？把静态加权中间价误当 microprice 会高估预测力；microprice 是鞅修正估计，不是量价加权公式 [[29]][ref29]。队列价值模型假设 FIFO；比例分配市场（部分期货按成交量比例分配，不按排队先后）位置逻辑不同。只靠提速不改善模型，速度竞赛是市场设计内生均衡 [[32]][ref32]，个体无法单独消除。

<a id="hft10-4-5"></a>
### 4.5 期权做市：理论价、波动率曲面与 Greeks 对冲

股票做市对着中间价报价，期权做市对着模型理论价报价。公允价来自期权定价模型（Black–Scholes 族），输入是标的价、行权价、到期、利率、股息与隐含波动率；其中隐含波动率需从市场价格反解，并按行权价、到期排成波动率曲面 [[33]][ref33]。

报价 = 理论值 ± 半价差；理论值随曲面 IV、标的价、剩余时间滚动重算 [[33]][ref33]。Delta 对冲：卖出看涨得到负 Delta（期权价对标的价格的敏感度），买入对应数量标的（或期货）使组合 Delta≈0，抵消标的小幅涨跌；Delta 随标的变化，Gamma（Delta 自身的变化率）衡量其变化速度，需要反复再平衡。Vega（对隐含波动率的敏感度）管理：组合对隐含波动率变化的敏感用 Vega 衡量，通常通过买卖其他行权价、到期的期权（价差、日历、风险反转）对冲，而非用标的 [[34]][ref34]。对冲频率与成本要权衡：对冲越勤，残留 Delta/Gamma 风险越小，但交易成本与滑点越高；机构在期货上对冲标的敞口，在期权腿间对冲 Vega。

一个期权做市商同时管理单标的上成百上千个行权价、到期系列，直接按每个系列做随机控制是高维问题。Baldacci、Bergault、Guéant 用组合 vega 近似把高维问题降维：在经典随机波动模型（如 Heston）下把问题化为低维泛函方程，用 Euler 格式加插值数值求解，即使组合很大也可处理 [[133]][ref133]。工程含义是按 vega 等风险因子聚合组合敞口后再报价与对冲，而不是逐系列独立优化。

先看一个敏感度例子（仅演示，非做市定价）。

```text
示例：某看涨期权 Vega=0.3，IV 从 10% 升到 11.5%（+1.5 个百分点），
期权价格上升 1.5 × 0.3 = 0.45 [[34]][ref34]。
完整的曲面定价与对冲配比计算不在本篇展开。
```

要看的信号包括隐含波动率曲面水平、偏斜（skew）、期限结构；已实现波动率与 IV 的差；组合净 Delta、净 Vega、Gamma、Theta [[33]][ref33][[34]][ref34]。事件（财报、FOMC）前后 IV 抬升，报价与对冲都要预留波动。

同时维护成百上千系列的报价（Citadel Securities 称其在美股上市期权跨逾百万系列提供连续流动性，约占美股期权成交量 30%+）[[35]][ref35]。报价更新、Delta/Vega 对冲腿、保证金与行权交割管理一体化；机构普遍自研交易与风控系统 [[36]][ref36][[37]][ref37]。

交易所有一层做市商保护机制（MMP）：撮合引擎内建可配置保护，做市商自设数量阈值或 Greeks（delta/gamma/vega）阈值，越限时自动撤掉保护范围内仍挂在簿上的报价，留出改价窗口，避免失控时被一次性全部成交；Knight Capital 2012 事件后这类机制在期权市场普及。Optiver 的公开主张是：阈值参数由做市商按自身风险承受力定制（可按单产品、分段或连接会话设范围），应支持实时电子查询、调整、重置，API 配置，并在越限撤单时实时通知做市商以便重置后重新报价 [[134]][ref134]。8.8 节 Deribit 规则书里的 MMP 是同一思想在单一加密交易所的落地。

机构层面还有中央风险账簿（central risk book）：分散在期权、期货、现货、ETP 各做市单元的库存不逐腿对冲，而是汇集到账簿集中仓储（warehouse），互相抵消形成“自然流动性”，再对净敞口统一管理。Optiver 2021 年公开介绍，其中央风险账簿汇集期权、期货、现货与 ETP 做市单元的全部风险，现货净头寸超 €10 亿，并经 Tradeweb 以 RFQ 向机构对手方提供紧报价 [[135]][ref135]。这解释了对冲频率与成本在机构规模上的实现方式：跨单元净额优先，剩余净敞口才用标的期货或期权腿对冲。

什么时候会亏？裸卖空期权承担尾部亏损；IV 跳升、Gamma 在临近到期时放大，对冲不及时会亏损。曲面套利（别处更便宜的同风险组合）会吃掉理论价差。

美股期权、国内期权、场外报价逻辑相通；国内期权做市义务与豁免见 4.6（CFFEX/SHFE 办法对期权单边市、深度价外有豁免条款）。

<a id="hft10-4-6"></a>
### 4.6 注册做市商的义务与返佣

做市不只是自己挂单。注册做市商承担约定时段内双边报价、最小报价量、最大价差等义务，换取手续费减收、返佣、报价义务豁免、信息或消息额度便利；返佣是价差之外的第二收入来源 [[28]][ref28]。

已核实的公开规则分四类。

- Nasdaq（美股）：Designated Liquidity Provider（DLP）按 ETP 行业 ADV 分档给每股返佣或月度津贴（如 Tier 1 >100 万股 ADV 为 $0.0034/股，Tier 2 为 $0.0040/股，低 ADV 档给月度固定津贴）；另有 NBBO 计划对建立最优报价的加流动性订单给 $0.0004/股返佣，并需满足月度合并成交量占比与 NBBO 流动性比例门槛 [[38]][ref38]。
- 中国金融期货交易所：双边报价分持续报价与回应报价；报价含合约代码、买卖价、双边数量，以限价申报；完成义务方可享手续费减收；开盘集合竞价、涨跌停板等情形免除报价义务；做市交易产生的频繁报撤单不构成异常交易 [[39]][ref39]。
- 上海期货交易所：同样区分持续报价、回应报价，交易所可给手续费减免与激励；单边市、深度价外期权等情形可不履行报价义务；完成义务方享权利 [[40]][ref40]。
- 加密交易所：Binance USDⓈ-M 永续、Bybit、OKX 等设做市商计划，提供 maker 返佣、更高限速与低延迟接入；汇总页列出各所最高返佣量级（Binance 约 0.005%–0.008%、Bybit 约 0.0025%–0.0125%），具体以交易所当期公告为准 [[41]][ref41]。

义务完成率（报价时长、达标价差/数量占比）直接决定返佣，系统需按时统计并向交易所报送；自有义务监控与纯模型报价分离。豁免情形（涨跌停、集合竞价、单边市、价外）要自动触发停报，避免违规报价。

什么时候该退出？义务与返佣不匹配时（义务成本 > 返佣 + 价差）应退出计划；规则按品种、月份调整。不得利用做市资格从事市场操纵、欺诈；频繁报撤单的豁免仅限于做市交易本身 [[39]][ref39][[40]][ref40]。

不同市场的差别：美股有指定流动性提供商、DMM 等分层；国内期货交易所按品种签约、分级评价排名；加密计划为商业协议而非法定义务。

## 5. 其他常见高频策略

<a id="hft10-5-1"></a>
### 5.1 信息变了，旧报价还没改：延迟/跨所套利

假设你盯着两个市场，同一件公开事情已经发生，其中一个市场的价格动了，另一个市场挂着的旧价还没来得及撤。更快的一方先按旧价成交，慢的原报价方则抢在成交前撤单。这是同一条新信息触发的“成交请求 vs 撤单请求”竞赛，前面讲过它的微观机制，这里看文献证据和工程口径 [[32]][ref32][[42]][ref42]。形态有两种：同一资产在不同场所留下旧报价；或者高度相关的两个资产（比如芝加哥的 E-mini 期货和纽约的 SPY ETF）一边已动、另一边没跟上，价差就是机械套利机会 [[32]][ref32]。

连续撮合里，信息在两地传播有物理下限。芝加哥（CME，Aurora, IL）到纽约（新泽西数据中心）单向光速约 4 毫秒，短于这个时间的跨地机会物理上抓不到，文献统计时直接剔除 [[32]][ref32]。机会存活 $t_{\text{arb}}$ 内，套利毛利 $\pi = (\Delta P - c_{\text{spread}} - c_{\text{fee}})\,q$，$\Delta P$ 是两边可成交价差，$c_{\text{spread}}$、$c_{\text{fee}}$ 是双边价差与费用，$q$ 是可成交数量；只有 $\pi>0$ 且本方请求先于撤单、抢单到达撮合引擎，钱才落袋 [[32]][ref32]。

先看 FCA 在伦敦股票市场观测到的一场典型竞争（文献统计口径，不是策略假设）。

```text
示例 1：FCA OP50 伦敦股票市场观测。
FTSE 100 单只股票平均每天 537 场延迟套利竞争；
按 8.5 小时 = 30600 秒交易时间折算：30600 / 537 ≈ 57 秒/场，约每分钟一场。
模态竞争中赢家比第一名失败者仅快 5–10 微秒；
单场平均价值略高于半个最小变动价位，平均约 £2；90 分位约 3 个价位、£7。
全样本“延迟套利税”（竞争利润/成交量）为 0.42 个基点：
0.42bp = 0.000042；每 £10 亿成交，成本 = 1,000,000,000 × 0.000042 = £42,000。
```

再看 ES 与 SPY 这对机械套利（QJE 2015 样本口径）。

```text
示例 2：ES（E-mini S&P 500 期货，芝加哥）与 SPY（ETF，纽约）机械套利（QJE 2015 样本口径）。
2011 年样本：单次机会中位盈利约 0.08 指数点，单次数量中位约 14 手 ES（约 7,000 股 SPY）；
机会中位持续时间从 2005 年的 97ms 缩短到 2011 年的 7ms；
单向光速下限约 4ms，短于 4ms 的机会不计入可抓取 Prize。
```

触发条件很直接：相关资产价格已变，目标报价没动；SIP（联合行情处理器，把各交易所行情汇总成全国最优报价再分发）的聚合行情和场所直连行情对不上 [[43]][ref43][[44]][ref44]。要盯的是机会预期存活时长、双边可成交量、信号到交易所的全链路延迟（决策加网络）、撤单先于成交的竞争概率。2005–2011 年机会中位时长从 97ms 降到 7ms，单次中位盈利（约 0.08 指数点）却基本不变——速度竞赛抬高的是参赛门槛，不是奖金规模 [[32]][ref32]。

真做起来，行情要直连各场所自行聚合，不能依赖 SIP；SIP 集中汇总有地理、聚合、传输三类延迟，地理延迟通常最大 [[43]][ref43]。SEC 2010 年概念文件记载，当时合并行情处理器平均延迟小于 10 毫秒，场所专有直连通常更快到达用户 [[44]][ref44]。网络上，芝加哥—纽约链路从直埋光纤（Spread Networks 2010 年建成，造价约 3 亿美元，往返从 16ms 降到 13ms）演进到视距微波（空气中光速更快，往返先后降到约 10、9、8.5、8.1ms）[[32]][ref32]。两腿分别在两地独立撮合，先成交一边就承担临时敞口，失败腿要快速补平；作为报价方，新信息到来后撤单请求必须先于抢单请求进入队列。

什么时候会亏：机会在本方订单到达前被更快者吃掉，或原报价方已撤单；只成交一边形成敞口。把持续性价差变动（资金成本、分红、跟踪误差）误当成临时噪声，文献把这类叫“bad arbs”并单独剔除 [[32]][ref32]。军备竞赛还会把单位机会利润吃掉，FCA 估计全球股票市场每年这个口径的资金池约 50 亿美元，但单场平均仅约半个价位 [[42]][ref42]。

不同市场：美股多场所并存，专有直连与 SIP 并行，Reg NMS 框架下反 trade-through（Rule 611），接入费上限见 6.3，co-location（把服务器托管在交易所机房隔壁）和个人直连是标准基础设施 [[44]][ref44]。境内股票现货 T+1，没有多场所连续竞价的套利空间；期货集中在单一交易所，跨所延迟套利土壤有限，托管资源由交易所体系分配（见 6.1、6.2）。外汇银行间 EBS/Reuters 平台分散，旧 firm quote 机会在 5.7 展开。

<a id="hft10-5-2"></a>
### 5.2 ETF 市价偏离参考净值时，谁把它拉回去

ETF 在二级市场按市价成交，同时授权参与商（AP，有资格用一篮子成份股向基金申购份额、或把份额赎回成篮子的机构）可以按申赎清单（PCF）用一篮子证券加现金差额向基金申赎。市价相对参考净值出现折溢价时，AP 一边在二级市场买卖 ETF、一边在一级市场申赎篮子，把价差兑现，反过来把市价拉回参考净值附近 [[45]][ref45]。除了“ETF ↔ 一篮子股票”，常用另一腿是股指期货（ETF 与期货基差），期现套利的完整建模见第 2 章，这里只把它当对冲腿。

盘中参考净值（美股 SEC 口径称 IIV = intraday indicative value，部分交易所称 IOPV；A 股称 IOPV 基金份额参考净值，Indicative Optimized Portfolio Value，即用成份股实时价格估算的盘中净值）按清单实时估算，约每 15 秒发布一次 [[45]][ref45][[46]][ref46]。两个方向的单位毛利：

$$\text{申购方向毛利} = P_{\text{二级卖出}} - (V_{\text{basket}} + c_{\text{pcf}})$$

$$\text{赎回方向毛利} = (V_{\text{basket}} - c_{\text{pcf}}) - P_{\text{二级买入}}$$

$V_{\text{basket}}$ 是篮子按可成交价计的价值，$c_{\text{pcf}}$ 是申赎费、现金差额调整与篮子冲击成本。

整组（creation unit，最小申赎单位）口径下，每股毛利必须在整组层面整体为正，并以可买入的篮子价格计价。申购方向：

$$N \cdot P_{\text{bid,二级卖出}} - V_{\text{basket,buy}} - C > 0$$

$N$ 是一个创设单位的股数，$P_{\text{bid,二级卖出}}$ 是二级市场可实际卖出价，$V_{\text{basket,buy}}$ 是按可成交价买入整组篮子的总成本，$C$ 是整组申赎费、结算与冲击成本；赎回方向对称，折价足够大才赎回。

先看每股口径（数字为假设演示）。

```text
IOPV = 100.00 元；二级市场买一 99.85（折价 0.15%），卖一 100.20（溢价 0.20%）。

赎回方向（买入折价 ETF → 赎回篮子）：
毛差 = 100.00 − 99.85 = 0.15 元/份
扣除申赎费与篮子双边价差合计 0.06 元/份后，净利 = 0.15 − 0.06 = 0.09 元/份。

申购方向（买篮子 → 申购 ETF → 二级卖出）：
篮子成本 100.00 + 费用 0.06 = 100.06 元/份，二级卖出 100.20，
净利 = 100.20 − 100.06 = 0.14 元/份。

按一个最小申赎单位 50,000 份计：
赎回方向净利 = 50,000 × 0.09 = 4,500 元；
申购方向净利 = 50,000 × 0.14 = 7,000 元。
```

再看整组可执行条件（数字为假设演示，已复算）。

```text
示例：整组可执行条件（数字为假设演示，已复算）。
创设单位 N=50,000 股，篮子买入成本 100.06 元/份等价，整组费用 C=15,000 元。

情形 A：二级可卖出价 P_bid=100.20。
毛收入 = 50,000 × 100.20 = 5,010,000 元
篮子成本 = 50,000 × 100.06 = 5,003,000 元
净额 = 5,010,000 − 5,003,000 − 15,000 = −8,000 元 < 0，不可创设。

情形 B：P_bid=100.50。
毛收入 = 50,000 × 100.50 = 5,025,000 元
净额 = 5,025,000 − 5,003,000 − 15,000 = +7,000 元 > 0，整组可创设。
```

信号是市价相对 IOPV 的偏离超过申赎与往返成本；篮子成分股盘口深度决定能买齐多少股而不推高成本。参数包括 PCF 清单权重、现金替代与现金差额、最小申赎单位（美股常见 50,000 份一档）、IOPV 更新周期（约 15 秒，粒度粗于逐笔行情）[[45]][ref45][[46]][ref46]。宽基篮子可达数百只成分股，要同时监控全部盘口并并行下单，任一只买不齐就得缩减申购腿数量。美式实物申赎多为 T 日办理，份额与篮子可用时点受结算规则约束；偏离盘中可能先扩大再收敛，需要库存与对冲腿管理。

亏在什么地方：篮子腿成交时市价已变，预期差额缩水；跨境 ETF 还承担标的市场时差与汇率风险。IOPV 15 秒刷新一次，刷新之间真实净值不可见，价格突变时信号滞后。成分股涨跌停、停牌导致篮子不可复制，套利腿只能部分成交。

**债券/信用 ETF 不一样。** 它的底层是公司债，大量债券一天内根本没有成交，NAV 只能靠模型估值或上一成交价，报告债券价格本身可能滞后；Jane Street 指出信用 ETF 盘中广播的价格水平往往比所报告的债券价格更准确 [[136]][ref136]。海外债券市场跨时区闭市时，ETF 仍在美股盘中交易，这时 IIV 与真实可成交篮子价值的偏离不能用股票 ETF 的实时篮子逻辑直接解释。压力市里做市商并不总走“买折价 ETF → 赎回篮子 → 卖债券”的闭环：判断抛售暂时，就把 ETF（或债券）暂存资产负债表等买方回归；抛售只集中在某几只 ETF，就用同板块其他 ETF 对冲；也可用 CDX 信用违约互换指数或相关期货对冲，交易衍生品通常比直接交易底层债券便宜 [[136]][ref136]。所以二级市场成交量放大不能直接推断套利闭环启动。篮子结构上分 pro-rata（收到的债券与基金持仓同权重）与 custom basket（豁免 1940 年法案后允许权重偏离，通常只含更少、更大的头寸）两类；一个创设单位常见整数为 10,000、25,000、50,000 或 100,000 股 [[136]][ref136]。压力期底层债券难卖、价差走阔、展示深度下降，ETF 自身出现 NAV 折价，强行按 pro-rata 赎回可能收到难以出手的零散债券。

中美规则差别：美股仅 AP 可直接向基金申赎，零售只在二级市场买卖，IIV/IOPV 由行情商分发，机制见 SEC 投资者公告 [[45]][ref45]。A 股股票 ETF 二级市场 T+1（当日买入次日方可卖出），债券 ETF、黄金 ETF、跨境 ETF、货币 ETF 支持当日回转（T+0）[[47]][ref47]。沪市份额使用规则（《ETF 业务实施细则》第二十二条）：标的为沪市/跨市场指数的，当日申购的份额同日可以卖出但不得赎回，当日买入的份额同日可以赎回但不得卖出，当日赎回的证券同日可卖但不得再用于申购 [[48]][ref48]。A 股“申购→卖出”与“买入→赎回”两条腿的可用时点不对称，不能照搬美股同日闭环。

<a id="hft10-5-3"></a>
### 5.3 两只股票常态同涨同跌，偏离了就做反向：统计套利与配对

两只或一组资产有常态价格关系，当前关系偏离时买便宜的一边、卖贵的一边，等它回归。基础价差配对前面算过，这里补模型化做法：把个股收益对市场/行业因子（PCA 主成分或行业 ETF）回归后的残差 $X_t$ 建模为均值回归过程，残差偏离过大时反向交易 [[49]][ref49]。经典日频配对交易用归一化价格距离选对，1962–1997 年样本上 top pairs 组合年化超额收益最高约 12%，且多数时期超过保守交易成本估计 [[50]][ref50]。

残差按 Ornstein–Uhlenbeck（OU，描述均值回归的连续随机过程）建模：

$$dX_t = \theta(\mu - X_t)\,dt + \sigma\,dW_t$$

$\theta$ 是回复速度，$\mu$ 是长期均值，$\sigma$ 是噪声强度。偏离衰减一半所需时间（半衰期）：

$$t_{1/2} = \frac{\ln 2}{\theta} \approx \frac{0.693}{\theta}$$

标准化信号 $z_t = (X_t - \mu)/\sigma_{\text{eq}}$，$\sigma_{\eq} = \sigma\sqrt{1/(2\theta)}$ 为均衡标准差；常用规则 $z>+k$ 做空、$z<-k$ 做多，回归到 0（或小阈值）平仓 [[51]][ref51]。实务上用离散 AR(1) 系数 $b$ 估计：$\theta \approx -\ln(1+b)/\Delta t$，$t_{1/2} \approx -\ln 2/\ln(1+b)$ [[51]][ref51]。

```text
拟合得 μ=0，θ=0.05/分钟，σ_eq=1.0，入场阈值 k=2，双边成本 0.3 个标准化单位。
半衰期 t_½ = 0.693 / 0.05 ≈ 13.9 分钟。
入场 z=+2.0（做空贵边），平仓 z=0：
毛利 = 2.0 − 0 = 2.0（标准化单位）；扣除双边成本 0.3，净 = 1.7。
若持有 30 分钟（约 2.2 个半衰期）仍未回归，按 OU 衰减预期剩余偏离
= 2.0 × (1/2)^(30/13.9) ≈ 2.0 × 0.226 ≈ 0.45，应评估止损或换仓。
```

关系是否稳定比拟合值重要：样本内拟合好不等于样本外成立，盯 $\theta$、半衰期、$\sigma_{\text{eq}}$、入场/出场阈值 $k$。Avellaneda–Lee 用 PCA 残差与行业 ETF 残差两条路线，论文报告 1997–2007 年 PCA 信号平均 Sharpe 约 1.44，ETF 因子组合在 2003 年以来子样本 Sharpe 约 1.51，且 2007 年 8 月出现明显回撤与去杠杆——均值回归关系会随市场结构衰减，同类策略集中平仓会放大回撤 [[49]][ref49]。

两腿数量按对冲比例 $\beta$ 匹配，但收益率 Beta 不是股数比：对收益率回归得到的 $\beta$ 度量资金敞口比例，不是两只资产的股数比例。买入 $q_A$ 单位 A 后，B 腿按经济敞口相等推导：

$$q_B P_B = \beta\, q_A P_A \quad\Longrightarrow\quad q_B = \beta\, q_A \frac{P_A}{P_B}$$

```text
示例（数字为假设演示，已复算）。
A：P_A=100.00 元，买入 q_A=10,000 股，敞口 = 1,000,000 元，回归 β=1.2。
B：P_B=50.00 元。
正确对冲股数 q_B = 1.2 × 10,000 × 100.00 / 50.00 = 24,000 股；
B 敞口 = 24,000 × 50.00 = 1,200,000 元 = 1.2 × 1,000,000 元，匹配。
错误做法：把收益率 β 当股数比按 1:1 配 10,000 股 B：
B 敞口仅 500,000 元，净敞口缺口 = 1,200,000 − 500,000 = 700,000 元，
在 A、B 价格差异大时留下明显方向风险。
```

高频版要快速监控数百只候选对的实时残差与 z-score；空头腿的借券成本与可借量直接决定可行性（美股 Reg SHO 见 6.3）。

退出不能只等残差回零。超时：超过预定持有窗口（如若干个半衰期）仍未回归，止损或换仓，别让均值回归仓位变成被动长期持仓，上面 30 分钟示例就挂接这条。共同关系改变：协整/回归关系破裂、因子暴露漂移、滚动 $\theta$ 显著下降时，停止新开仓并平仓，旧均值不能继续当回归目标。风控限额：组合波动率、单边净敞口、借券成本或可借量恶化触发减仓。若 A 发生并购、重大盈利、增发、评级调整等改变独立价值的事件，残差偏离可能是新均衡而非临时噪声，继续“越跌越买”加仓会把均值回归变成不断扩大敞口的方向交易，先判断关系是否仍成立再去留。

什么时候会亏：关系从均值回归变成结构性漂移（基本面分化、行业轮动），价差持续扩大不止损会深亏；样本过拟合，历史 Sharpe 高、样本外失效，2007 年 8 月量化挤兑中同类策略集中平仓加剧回撤，Avellaneda–Lee 有专门讨论 [[49]][ref49]；高频版价差薄，往返价差与费用可能吃掉全部预期回归收益。

不同市场：美股融券渠道成熟，可做市场中性多空，T+0 允许日内开平。A 股股票现货 T+1 且融券渠道收紧（见 6.1），股票腿日内对冲难做，同类思路更多落在 ETF、期货、期权之间的相对价值。半衰期过短（几个 tick）利润常被价差吞没，过长则占用资本、回撤大 [[51]][ref51]。

<a id="hft10-5-4"></a>
### 5.4 期货先动、ETF 后跟：领先—滞后（lead-lag）

流动性好、信息效率高的资产先变动，相关资产稍后跟随。最典型的是指数期货领先成分股/ETF：文献用毫秒 DTAQ 数据观测到 ETF 对 CME 期货成交有约 5 毫秒的反应（芝加哥信号到达纽约所需时间），反向反应不显著，价格发现几乎全部发生在 CME [[52]][ref52]。跨所之间也有同资产/近资产的领先—滞后：更活跃场所的成交先动，慢场所报价后调。

对两条异步观测的价格序列，用 Hayashi–Yoshida 交叉协方差估计器计算滞后 $\tau$ 处的协方差峰值，避免把不规则 tick 强行等间隔抽样带来的失真，峰值对应的 $\tau$ 就是估计领先时间 [[53]][ref53]。Huth–Abergel 在法国市场 tick 数据上发现：流动性最好的资产（成交间隔短、价差窄、波动小、换手高）倾向领先小盘股；仅用领先方过去信息预测滞后方下一中间价方向，准确率约 60%，显著高于只用滞后方自身信息，但用市价单朴素交易覆盖不了价差成本 [[53]][ref53]。

**时间戳口径是个坑。** 验证领先关系必须用策略实际可见的统一时间口径：期货序列按交易所撮合时间戳排序、ETF 序列按本地接收时间排序，测得的“领先 $\tau$”会混入时钟偏差、串行处理与传输延迟，可能把纯延迟差误判成信息领先。可用信号要同时满足：相关市场信息已到达本地、目标市场价格仍可成交、订单抵达时预期收益仍超过成本。Budish–Cramton–Shim 报告 2011 年样本中，ES 与 SPY 等权中间价收益的日度中位相关系数在 10 毫秒窗口为 0.1016、1 毫秒窗口仅 0.0080，长窗口接近 1、高频尺度相关性瓦解，由此产生机械套利机会；论文脚注还专门检验时钟口径：无论按纽约时间（把芝加哥事件延后 4ms 对齐）、芝加哥时间，还是直接把两地时间混排，1ms 相关都基本为零——混排不会制造虚假高相关，但会让领先方向与延迟归属判断出错，回测必须先统一时钟口径再估计 $\tau$ [[52]][ref52]。

```text
E-mini 上涨 0.10 指数点，预期 ETF 补涨 0.08；双边买卖价差合计 0.04。
在 5ms 窗口内以可接受价格买入 ETF：预期净 = 0.08 − 0.04 = 0.04。
若晚到 20ms，补涨已完成，只能以 0.09 追入：
净 = 0.08 − 0.09 − 0.04 = −0.05，亏损。
```

盯领先方成交/报价变动的方向与幅度、估计滞后 $\tau$（毫秒级）、跟随方尚未调整的报价深度。日内季节性明显：lead-lag 在宏观数据发布、开盘等事件附近显著增强，不是全天恒定 [[53]][ref53]。必须在估计的 $\tau$ 窗口内完成跟随方下单，跨地受物理传播下限约束（见 5.1）。对冲版（卖领先、买滞后）追求中性，未对冲的方向版承担单边价格风险。

什么时候会亏：相关性在事件窗口外消失，60% 的方向准确率扣掉价差后所剩无几 [[53]][ref53]；领先关系反转（慢场所因流动性变好而领先），参数滞后估计失效；只追到已经补完的价格，成为最后接单方。

不同市场：美股期货（芝加哥）—ETF/股票（新泽西）跨城结构是经典场景，微波链路专门服务此传导 [[52]][ref52]。境内股指期货与现货同在本地（上海/中金所），物理延迟差小，lead-lag 窗口更短，且现货 T+1 限制跟随腿当日平仓。

<a id="hft10-5-5"></a>
### 5.5 从盘口净方向猜下一小段价格：OFI、队列不平衡与盘口深度学习

不预测基本面，直接从订单簿事件（挂单、成交、撤单）的净方向推断下一小段价格变动。Cont–Kukanov–Stoikov 证明短时间内价格变化主要由最优买卖价上的订单流不平衡（OFI，一个窗口内新挂单减撤单减被成交的净方向数量）驱动，$\Delta P$ 与 OFI 呈线性关系，斜率与市场深度成反比，且跨股票、跨时间尺度稳健 [[54]][ref54]。队列不平衡（买一/卖一挂单量之比）是更简单的单档版本，Gould–Bonart 在 10 只 Nasdaq 流动性股票上用逻辑回归证实它对下一中间价方向有显著预测力，大 tick 股票改善明显、小 tick 股票中等 [[55]][ref55]。

单档 OFI 对一个时间窗口、一边盘口汇总：新挂单与提价为正，被主动成交与撤单为负，档位下移把剩余数量转出本档也计负；买卖两侧相减得净 OFI：

$$\Delta P_{k,i} = \beta_i\,\text{OFI}_{k,i} + \epsilon_{k,i}, \qquad \beta_i \propto 1/\text{Depth}_i$$

Xu–Gould–Howison 把单档扩展为多层向量 MLOFI，用 6 只 Nasdaq 流动性股票证明每多纳入一个价位，样本外拟合优度继续改善，深层订单流也参与价格形成 [[56]][ref56]。深度学习路线 DeepLOB 用卷积层提取盘口空间结构、LSTM 捕捉时间依赖，在基准 LOB 数据集上超过此前方法，并在 LSE 一年实测报价上保持稳定样本外准确率，特征可迁移到未训练品种 [[57]][ref57]。

**同期解释不是预测。** Cont–Kukanov–Stoikov 的 OFI 是同一窗口内 OFI 对同一窗口价格变化的同期（contemporaneous）线性解释，$\Delta P_{[t,t+\Delta]}$ 与 $\text{OFI}_{[t,t+\Delta]}$ 同期回归，不能直接当作“用过去 OFI 预测未来价格”。要做预测，标签必须移到信号窗口之后（如 $\text{OFI}_{[t,t+\Delta]} \to \Delta P_{[t+\Delta,t+2\Delta]}$），并在样本外检验；把同期相关误当预测力是这类信号最常见的回测错误。

```text
100ms 窗口的单档 OFI。
买一档：新挂 1000 股，撤单 200 股，被主动卖出成交 300 股
  → 买方净流 = 1000 − 200 − 300 = 500 股。
卖一档：新挂 400 股，撤单 100 股，被主动买入成交 600 股
  → 卖方净流 = 400 − 100 − 600 = −300 股。
OFI = 500 − (−300) = 800 股（买方方向）。
平均深度 2000 股，归一化 β=1：预期相对压力 = 800/2000 = 0.40 档当量；
最小档 0.01 元时预期移动量级 ≈ 0.004 元，需先覆盖买卖价差与费用才可能为正。
```

参数看 OFI 窗口长度、纳入层数（MLOFI）、当前深度、队列不平衡比值；深度学习路线还要历史窗口长度与标签 horizon（预测未来 k 档/秒的涨跌）[[56]][ref56][[57]][ref57]。信号预期中间价变动 $\hat\alpha$ 必须同时覆盖成本门槛：

$$\hat\alpha > \frac{s}{2} + c_{\text{退出}} + c_{\text{手续费}} + c_{\text{延迟滑点}} + r_{\text{风险补偿}}$$

```text
示例（数字为假设演示，已复算）。
半价差 s/2=0.015，退出成本 0.010，手续费 0.002，延迟滑点 0.008，风险补偿 0.010。
门槛合计 = 0.015+0.010+0.002+0.008+0.010 = 0.045。
信号预期 α̂=0.050 > 0.045，边际通过；
若 α̂=0.040 < 0.045，即使方向判断正确也无交易价值。
若预测标签直接针对未来可成交买/卖价，不再重复扣对应的退出价差。
```

逐事件重建盘口（行情接入的基本功），延迟到微秒级；信号窗口短，决策与下单必须在窗口内完成。深度学习模型要高质量逐笔数据、训练/样本外切分防前视，输出接实时风控。

什么时候会亏：OFI 是同期相关而非因果保证，撤单可以瞬间反转账面不平衡；大/小 tick 股票预测强度不同，模型跨品种直接迁移会衰减 [[55]][ref55]；黑箱模型在极端行情下失效路径不可解释，要独立限额与止损。

不同市场：美股、期货逐笔数据公开度高，是这类研究的主要样本市场。A 股 Level-2 逐笔委托/成交可用，但 T+1 使信号只能用于不可当日平仓的方向判断或对冲，不能直接转成日内回转。

<a id="hft10-5-6"></a>
### 5.6 把返佣当独立目标：maker-taker 与 inverted 费率结构

maker-taker 结构下，提供流动性的挂单方（maker，先挂单等成交的一方）每股领返佣（交易所按成交股数给 maker 的报酬），吃单方（taker，立即吃掉已有挂单的一方）付费，交易所保留差额。SEC EMSAC 备忘录示例：taker 付 $0.003/股、maker 领 $0.002/股，交易所留 $0.001/股 [[58]][ref58]。返佣本来就是做市收入的一部分，这里讨论“把返佣作为独立目标”的策略及其风险。反向的 inverted（taker-maker）结构向吃单方返佣、向挂单方收费，用于在价差内创造更细报价网格 [[59]][ref59][[60]][ref60]。

被动成交每股净收益 = 价差毛利 + 返佣 $r_{\text{maker}}$ − 逆向选择损失（自己挂的单总在对方向自己有利时被人吃掉）− 费用；inverted 下主动成交每股 = 价格改善 − 付费 $f_{\text{maker}}$ + 返佣 $r_{\text{taker}}$。Rule 610 接入费上限、净价与展示价不一致等制度问题见 6.3，这里不重复 [[58]][ref58]。

```text
示例 1：maker-taker 单股经济（SEC 备忘录示例费率口径）。
taker 费 $0.003/股，maker 返佣 $0.002/股，交易所留 $0.001/股。
被动挂单成交 10,000 股：返佣 = 10,000 × 0.002 = $20。
若该批挂单承担逆向选择亏损 $35（价格反向 3.5 美分 × 10,000 股）：
净 = 20 − 35 = −$15，返佣不足以补偿 adverse selection。
```

```text
示例 2：inverted 场所费率（Cboe EDGA 2024-11-01 转型前规则，Federal Register 文件口径）。
吃单方 remover 每股领 $0.00160 返佣，挂单方 maker 每股付费；
10,000 股主动成交返佣 = 10,000 × 0.00160 = $16。
转型 maker-taker 后，同样 10,000 股 remover 改为付费 $0.00300/股 = $30。
```

要盯各场所费率表（maker 返佣、taker 费、分层量级门槛）、净价差（展示价 ± 费用）、排队位置与成交概率。Gregoire 用 2016 Tick Size Pilot 的外生冲击发现 inverted 份额上升改善定价效率与流动性、降低短期波动，但 inverted 也制造额外队列并可能扭曲展示价 [[59]][ref59]。路由决策要同时比较展示价与净价，跨场所维护多张队列的排队预期；高频批量被动成交，对撤单速度与库存回报敏感。

什么时候会亏：“为返佣而挂单”在没有价差保护时变成逆向选择出口，信息交易者专门吃你的挂单，返佣覆盖不了损失（示例 1）。费率表随场所竞争频繁调整（如 EDGA 2024 年从 inverted 转回 maker-taker），模型参数过期即亏 [[60]][ref60]；券商不把返佣转给客户时产生路由利益冲突，SEC 备忘录专门讨论了这点 [[58]][ref58]。

不同市场：美国股票 maker-taker/inverted 并存，Rule 610 接入费上限与 2024 年修订见 6.3。境内期货/股票无每股返佣制度，该策略不适用；加密交易所的分级 maker/taker（含 VIP 负 maker 费率）见 6.5 与第 8 章。

### 5.7 三种货币绕一圈多出来的钱：外汇三角套利

三腿兑换的基本乘法前面算过，这里补市场实证与成本结构。加密交易所上的同类三角/循环套利由第 8 章展开。

三种货币（如 USD、EUR、JPY）之间，直接交叉汇率与两条间接兑换路径应当一致；不一致时沿闭环兑换一圈回到起点，多出的金额即毛利。外汇没有中央订单簿，价格来自 EBS、Reuters 等银行间电子经纪平台的 firm quotes（可成交实价），三腿分布在不同货币对 [[61]][ref61]。

无套利条件：$S_{\text{EUR/USD}} \times S_{\text{USD/JPY}} = S_{\text{EUR/JPY}}$（方向取 bid/ask 后组合）。闭环毛利：

$$\pi = N_0 \cdot q_{\text{USD/JPY}}^{\text{bid}} \cdot q_{\text{EUR/JPY}}^{\text{ask}} \cdot q_{\text{EUR/USD}}^{\text{bid}} - N_0$$

每腿必须用可成交的 bid/ask，而不是中间价。

```text
100 USD 闭环。
腿1 卖 USD 买 JPY：150.00 → 100 × 150.00 = 15,000 JPY。
腿2 买 EUR 付 JPY：160.00 → 15,000 / 160.00 = 93.75 EUR。
腿3 卖 EUR 买 USD：1.0680 → 93.75 × 1.0680 = 100.125 USD。
毛差 = 0.125 USD/100 USD = 12.5bp。
扣除三腿点差与手续费合计 10bp 后净 = 2.5bp；
若任一腿报价在到达前移动一个点差，净差可能归零。
```

信号看三货币对 bid/ask 与深度、闭环乘积偏离 1 的幅度、机会存活时间、对手方信用额度（EBS 上弱银行只能与有授信的银行成交）[[61]][ref61]。三腿须近似同时成交，依赖平台直连与快速路由；EBS firm quote 有可成交数量上限。外汇现货 T+2 结算，套利口径通常只比较即期可成交价，不占用远期。

什么时候会亏：Fenn 等用高频可成交价格发现，机会确实存在但持续时间短、幅度小，且需要高得不现实的成交命中率才能长期盈利，市场整体接近内部一致 [[62]][ref62]。Ito 等基于 EBS 12 年 tick 数据：机会通常只持续几秒，1 秒内消失的概率从 1999 年不足 50% 升到 2009 年约 90%，机会数量随算法直连普及显著下降 [[61]][ref61]。一条腿成交、另两条未成交即留下单边货币敞口。

不同市场：银行间外汇去中心化、24 小时运行，无统一涨跌停；机会集中在活跃波动时段 [[62]][ref62][[61]][ref61]。

<a id="hft10-5-8"></a>
### 5.8 机器先于人工读完新闻：事件/新闻驱动高频

公开新闻或宏观数据发布后，机器先于人工完成“提取主体—判断方向—下单”，在价格完成调整前建仓。合规前提是所有参与者同时获得公开信息，差别只在解析与执行速度。von Beschwitz–Keim–Massa 用 RavenPack 对 Dow Jones Newswire 的机器指标研究：从发稿到输出相关度/情绪指标约 300 毫秒，覆盖分析使前 5 秒的绝对收益反应份额提高 1.3 个百分点、成交量份额提高 0.5 个百分点，市场价格调整更快 [[63]][ref63][[64]][ref64]。

**速度与精度是两种价值。** Foucault–Hombert–Roşu 把知情交易拆成两种形式：信息更准确（精度优势，传统 Kyle 类模型），以及比其他投资者更快获得公开信息（速度优势）。在保持信息精度不变的模型对照下，速度优势产生独立的 news trading component：知情者订单流波动更大、占成交量比例更高，并与极短期收益正相关；但快速投机者实现的利润中很大部分仍来自长期价格变化，而非仅靠抢那几毫秒 [[138]][ref138]。提速只买到极短窗口的反应权，不提高判断质量，速度收益必须单独用成本门槛检验。

事件冲击的价格调整通常集中在发布后最初数秒；策略比较“发布后 $t$ 秒内已实现反应份额”与全反应，目标窗口内建仓的预期边际收益 = 预期调整幅度 − 双边价差 − 费用。RavenPack 口径：前 10 秒已纳入 35.7% 的总反应（有分析覆盖），对照为 28.4% [[64]][ref64]。

```text
发稿 → 机器指标输出 ≈ 300ms；策略在 300ms–2s 内完成建仓。
预期事件驱动调整 0.10 元，双边成本 0.04 元，预期净 = 0.06 元/股。
若人工/慢渠道在 30s 后才反应，该 0.06 元边际已被先到者拿走。
```

信号看新闻情绪/相关度标签、发布时刻（精确到毫秒）、历史同类事件的价格反应分布，以及宏观日历（非农、CPI、议息）的固定时刻。锁室（lock-up）争议：传统政府数据锁室让核准媒体在正式发布前约 30 分钟拿到数据，2012 年国会证词已指出锁室内设备可直连自动交易模型，破坏公平获取 [[65]][ref65]。私营数据方面，2013 年汤森路透曾向付费 HFT 客户提前 2 秒发布密歇根大学消费者信心指数，经纽约州总检察长施压后暂停；暂停后该指数发布后 10ms 内 SPY 成交约 500 股，2012 年同期窗口约 200,000 股 [[66]][ref66]。

文本解析（实体识别、情绪、事件分类）低延迟完成，行情端预先挂好条件单；固定时刻事件可预载对冲参数。要区分“高相关高影响”新闻与噪声标签，避免误报触发反向交易。

什么时候会亏：误判情绪或相关度，机器把低相关文章当高相关交易（false positive），价格短暂反向 [[64]][ref64]；事件落地即“买预期卖事实”，方向与标签相反，流动性瞬间稀薄，冲击成本高；提前获取非公开/付费早发数据可能触及公平披露与欺诈边界，2013 年密歇根案例即争议先例 [[66]][ref66]。研究/回测的常见陷阱：预期值必须取发布前快照（调查均值、衍生品隐含），发布后的修正值不得回填为当时已知数字；同一事件被通讯社、转载、推送多次发送，按条数计数会重复放大反应；“denies / not / failed to”等否定结构会反转方向，纯情绪词典容易误判；同名公司、相同 ticker、名人与公司同名需消歧；时间戳要区分稿件发布、本地接收、机器处理完成三个时刻，三者差即解析与传输延迟，不能混写成一个事件时间。

不同市场：美股/美债宏观数据由 BLS、BEA、美联储等按固定时刻发布，锁室制度历史与改革见国会证词 [[65]][ref65]。A 股公告与宏观发布节奏不同，T+1 限制新闻驱动的日内回转平仓。

### 5.9 押波动率高低：波动率套利与期权平价、箱式价差

比较期权隐含波动率（IV，市场报价里反推出的波动率）与模型估计的未来实现波动率（RV，随后真实走出的波动）：IV 偏高就卖期权组合并 Delta（期权价对标的价格的敏感度）对冲，偏低则买入，把赌注从标的方向转到波动率高低上。CBOE 指出长期看 SPX 期权隐含波动率相对后续实现波动率存在溢价，市场参与者用 VIX 期货/期权及其他波动率相对价值策略利用这一差异 [[67]][ref67]。看涨看跌平价的基础算例前面给过，这里不重复。

Delta 对冲后期望毛利一阶近似为 $(\text{RV} - \text{IV}) \cdot \text{Vega} \cdot \Delta t$ 的积分差；同时管理 Vega、Gamma（Delta 自身的变化率）与时间衰减（theta）。高频层面对冲要求标的每跳都能快速调 Delta。

```text
30 天期权 IV=22%，模型 RV=20%，组合 Vega=100（IV 每变 1 个百分点，组合价值约变 $100）。
卖出偏贵期权并 Delta 对冲；若 IV 收敛到 21%（−1pt）：
毛利 ≈ 100 × 1 = $100。
实际 RV 低于 IV 的 2 个百分点提供安全垫，但需扣除 Gamma、theta 损耗与多次对冲成本。
```

参数看 IV 曲面（不同行权价/到期）、RV 估计窗口、Vega/Gamma/theta、对冲触发阈值。标的腿高频对冲需要低延迟行情与下单；期权链报价分散，成交依赖做市商报价。

什么时候会亏：RV 意外高于 IV（事件跳空），卖波动率组合亏损放大；Gamma 在临近到期时非线性增大；对冲不及时留下 Delta 敞口，策略退化为方向赌注。美股期权市场深度大、做市充分；境内期权品种少、流动性集中在近月，高频波动率空间有限。期权怎么做市报价、怎么对冲，见 4.5 节。

#### 期权平价与箱式价差：隐含的无风险借贷

与 5.9 押波动率高低不同，这里利用同一标的、同一行权价、同一到期的看涨看跌之间的无套利恒等式。欧式、无股息期权的 put-call parity：

$$C - P = S - K\,e^{-r\tau}$$

变形 $C + K e^{-r\tau} = P + S$（买看涨 + 持有现值 $K$ 的零息债 = 买看跌 + 持有现货）；买看涨、卖看跌（同 $K$、同 $\tau$）构成以 $K$ 为执行价的合成多头远期，反向为合成空头 [[147]][ref147][[148]][ref148]。含股息版本为 $C - P = S - \mathrm{PV}(D) - K e^{-r\tau}$。市场报价的 $C-P$ 偏离右侧、扣除成本后即为转换/反转套利空间，高频层面对冲要求四腿/两腿报价可同时成交。

```text
示例（教学假设）：欧式、无股息，S=5000，K=5000，r=5%，τ=0.25 年。
  K·e^{−rτ} = 5000·e^{−0.0125} = 5000 × 0.987578 = 4937.89
  C − P = S − K·e^{−rτ} = 5000 − 4937.92 = 62.11 点
即同一行权价、同一到期的看涨与看跌价差恒等于现货减行权价现值；
若市场报价的 C−P 偏离 62.11 点超过成本，即出现转换/反转套利空间。
```

**箱式价差（box）：锁定到期固定支付的隐含利率交易。** box 由两个合成远期反向叠成：在 $K_1$ 买合成多头（买 $C_{K_1}$、卖 $P_{K_1}$），在 $K_2$ 卖合成空头（卖 $C_{K_2}$、买 $P_{K_2}$），四腿同一到期。无论标的到期落在何处，组合到期固定支付 $K_2-K_1$，与标的股价风险无关，本质是用期权合成一笔零息借贷 [[146]][ref146][[147]][ref147]。买入 box 的净借方 $D$ 满足：

$$K_2 - K_1 = D\,e^{r_{\text{box}}\tau} \;\Rightarrow\; r_{\text{box}} = \frac{1}{\tau}\ln\frac{K_2-K_1}{D}$$

买 box = 按 $r_{\text{box}}$ 借出资金（期初付 $D$，到期收 $K_2-K_1$）；卖 box = 按 $r_{\text{box}}$ 借入资金（期初收 $D$，到期还 $K_2-K_1$）。市场比较 $r_{\text{box}}$ 与货币市场利率、券商保证金利率，出现利差即套利/融资替代机会；Cboe 官方页给出 SPX box 实际借贷利率与券商保证金利率、短国债利率的对比统计 [[146]][ref146]。CME 2024 年另有一篇箱式价差作为融资工具的官方文章，仅作延伸阅读，正文不引用其中数字 [[149]][ref149]。

```text
示例（教学假设）：欧式股指期权，K1=5000，K2=5100，τ=0.25 年，
买入 box 净借方 D=97.5 指数点；到期固定支付 K2−K1=100 点。

隐含连续年化利率：
  100 = 97.5·e^{r·0.25}
  r = (1/0.25)·ln(100/97.5) = 4·ln(1.025641) = 4 × 0.025318 ≈ 10.13%
单利口径：r = (100/97.5 − 1)/0.25 ≈ 10.26%。
若同期货币市场利率为 8%，该 box 隐含 10.13% 高于市场，
卖出 box（借入）成本偏高、买入 box（借出）划算；反之亦然。
```

前提与风险：必须是欧式期权（美式提前行权会破坏固定到期支付），SPX 等现金结算欧式指数期权才适用 [[148]][ref148]；四腿同时成交风险、买卖价差与手续费会侵蚀薄利差。这是相对价值/融资工具，不是方向性策略，与 5.9 的波动率套利（IV vs RV）分开。

<a id="hft10-5-10"></a>
### 5.10 集合竞价：NOII、虚拟不平衡与清算价预测

集合竞价把一段窗口内累积的买卖申报一次性集中撮合，按单一价格成交。Nasdaq 收盘集合竞价（Closing Cross）在 16:00 ET 计算一个使配对股数最大化的价格，即 Nasdaq Official Close Price（NOCP），全部交叉订单按这一价成交；Nasdaq 称收盘竞价约占其日均成交量的近 10%，是指数基金等基准定价的来源 [[151]][ref151]。公开的不平衡信息是这类策略的研究对象：Nasdaq 在竞价窗口内发布净订单不平衡指标（NOII，Net Order Imbalance Indicator），包含配对股数（Paired Shares，当前参考价下能配对的收盘股数）、不平衡方向（Imbalance Side，B/S/N）、不平衡数量（Imbalance Quantity，还在找对手流动性的收盘股数）、当前参考价（Current Reference Price，BBO 内使配对最大、不平衡最小、距中点最近的价格）；15:55 后还给出两个指示清算价——Near Indicative Clearing Price（纳入连续市场订单时此刻的交叉价）与 Far Indicative Clearing Price（仅按收盘兴趣 MOC/LOC/IO 计算，不含连续订单）[[151]][ref151]。围绕这些信息的正当研究方向有两个：预测最终清算价相对连续市场可成交价的偏离；在规则允许的窗口内承接另一方的不平衡流动性需求。买方不平衡大并不等于跟随买入有利可图——响应不平衡的新增卖单会随时进入，指示价与最终清算价随之改变，NOII 是动态更新的中间状态，不是成交承诺 [[151]][ref151]。

**Nasdaq 时点与撤改规则（ET）。** 15:50 起接受 MOC/LOC/IO，NOII 每 10 秒发布一次；15:55 停止接受 MOC，NOII 改为每秒发布并增加 Near/Far 指示清算价，LOC 可在 posting 后进入但不得撤销或修改，IO 可提交到 16:00；15:58 停止接受 LOC；16:00 开始交叉 [[151]][ref151]。三种抵消不平衡的方式：LOC（带价格立场、参与价格发现）、可一直提交到交叉开始的连续市场订单、Imbalance-Only（IO，流动性提供单，交叉时由当时 Nasdaq BBO 重定价，不保证成交）[[151]][ref151]。

**A 股现货规则对照。** 沪深两市均采用：开盘集合竞价 9:15–9:25，连续竞价 9:30–11:30、13:00–14:57，收盘集合竞价 14:57–15:00；9:20–9:25 与 14:57–15:00 两个阶段交易主机不接受撤单申报，其余申报时间未成交部分可撤销（深交所规则原文如此；上交所同口径条款以上交所现行规则为准）[[152]][ref152][[68]][ref68]。上交所 2018 年收盘机制调整公告明确：收盘集合竞价阶段“可以申报，不可撤单”，行情揭示同开盘集合竞价 [[153]][ref153]。集合竞价期间交易所揭示虚拟参考价、虚拟匹配量、虚拟未匹配量（深交所定义：参考价为截至揭示时全部申报按集合竞价规则虚拟成交的价格，匹配量为虚拟成交数量，未匹配量为参考价位上不能虚拟成交的买方或卖方剩余量）[[152]][ref152]。成交价按最大成交量原则确定：可实现最大成交量的价格；高于该价的买入与低于该价的卖出全部成交；同价买卖至少一方全部成交；所有交易以同一价格成交 [[152]][ref152]。开盘价由集合竞价产生，不能产生时以连续竞价第一笔成交价为开盘价；收盘价由收盘集合竞价产生，不能产生时取最后一笔交易前一分钟成交量加权平均价 [[68]][ref68]。

**中金所股指期货规则对照。** 开盘集合竞价为 9:10–9:15，9:10–9:14 为指令申报时间，9:14–9:15 为指令撮合时间 [[4]][ref4]。《中国金融期货交易所交易细则》第三十九条：集合竞价分申报与撮合两段，申报时间不接受市价指令，也不接受附加即时全部成交或撤销（FOK）、即时成交剩余撤销（IOC）属性的限价指令；撮合时间不接受任何指令申报 [[154]][ref154]。第四十一条：集合竞价采用最大成交量原则，高于竞价价的买入申报、低于竞价价的卖出申报全部成交，同价按买卖申报量较少的一方成交 [[154]][ref154]。股指期货没有收盘集合竞价：收盘价为当日最后一笔成交价格，当日结算价取最后一小时成交量加权平均 [[154]][ref154][[4]][ref4]。

跨市场共性约束：截止时间（MOC/LOC/IO 各自停止接受时点不同）、截止后不可撤改、实际获配数量按比例而非按申报量、竞价结束后留下的库存要承担到下一交易时段的价格波动。A 股股票 T+1（见 6.1），收盘竞价买入的股票当日无法卖出，隔夜库存只能等次日处理。

```text
示例：收盘竞价承接买方不平衡（假设，已复算）。
15:58 NOII：买方不平衡 5,000 股，Near 指示清算价 $50.20；连续市场中间价 $50.10
（bid $50.08 / ask $50.12）。策略判断最终清算价落在 $50.15–$50.25，
以 LOC 卖出 2,000 股 @$50.15 承接部分不平衡。

情形 1：全部获配，成交价 $50.20。
竞价改善 = (50.20 − 50.10) × 2,000 = $200。
收盘后库存：空头 2,000 股。次日开盘参考 $50.28（高开 $0.08）：
库存盯市损益 = (50.20 − 50.28) × 2,000 = −$160；净 = 200 − 160 = +$40（未计费用）。
对照：次日开 $50.10，库存损益 = (50.20 − 50.10) × 2,000 = +$200，净 = +$400；
次日开 $50.35，库存损益 = (50.20 − 50.35) × 2,000 = −$300，净 = −$100。

情形 2：仅 60% 获配（1,200 股 @$50.20）。
竞价改善 = (50.20 − 50.10) × 1,200 = $120；
次日 $50.28 的库存损益 = (50.20 − 50.28) × 1,200 = −$96；净 = +$24。
未成交 800 股不形成库存，不承担隔夜风险。
```

信号看 NOII/虚拟未匹配量的方向与数量随时间的变化率、Near 与 Far 指示价之差（连续市场兴趣与收盘兴趣的分歧）、当前参考价相对连续 BBO 的位置、距截止时间的剩余秒数、自身申报类型（LOC/IO/连续单）与获配比例假设。执行上要在截止窗口内持续接收并解析 NOII/虚拟行情，按各订单类型的停止接受时点排程提交；截止后不可撤单，提交前必须把获配比例与隔夜库存计入决策；A 股 9:20 后、14:57 后不可撤单，模型不得假设临期纠错。

什么时候会亏：指示价在最后几秒漂移导致获配在不利价；获配不足使计划的对冲腿落空；隔夜库存反向跳空（A 股 T+1 无法当日回转）；把 NOII 不平衡当成确定性方向而反向加仓。收盘竞价相关的价格操纵边界见第 7 章，不得通过集中申报影响收盘价。

不同市场：美股 Nasdaq/NYSE 收盘竞价数据公开、机构基准交易量大；A 股开盘与收盘竞价均有虚拟参考价揭示但无 NOII 式的 Near/Far 指示价；中金所仅有开盘集合竞价，无收盘竞价。

### 5.11 执行层：TWAP/VWAP 基准与 Almgren–Chriss 均值—方差执行

先定位：执行算法降低成本，不是独立 alpha。TWAP（Time-Weighted Average Price，时间加权平均价）与 VWAP（Volume-Weighted Average Price，成交量加权平均价）首先是执行基准，也用作同名拆单算法：TWAP 类把已定方向、已定总量的订单按时间均匀切分；VWAP 类参照市场成交量曲线分配子单，使自身平均成交价贴近市场 VWAP。二者接收的是“已经决定要买/卖多少”的目标，解决“怎么完成”，不预测价格方向，本身不构成独立收益来源。判断收益来源要回到原始交易目标：提供流动性赚价差、复制价差、预测价格，还是降低一笔已有交易的执行成本；机器学习、强化学习在这一层只优化子单时机与主被动选择，不改变收益机制本身。

Almgren 与 Chriss 把固定持仓 $X$ 在期限 $T$ 内清算写成预期成本与成本方差的权衡（原论文需付费获取，以下连续时间形式以可公开访问的 Gatheral 讲义为准）[[155]][ref155][[156]][ref156]：

$$\min_{x}\ \mathbb{E}[C(x)] + \lambda\,\mathrm{Var}[C(x)],\qquad x(0)=X,\quad x(T)=0.$$

$x(t)$ 为剩余持仓轨迹，$C$ 为相对初始参考价的执行短缺（implementation shortfall），$\lambda\ge 0$ 为成本风险厌恶系数。模型把冲击分为永久冲击 $g(v)=\gamma v$ 与临时冲击 $h(v)=\eta v$（$v$ 为成交速率），未受冲击价格按算术布朗运动演化 [[155]][ref155]。连续线性冲击下，欧拉—拉格朗日方程 $\ddot{x}-\kappa^{2}x=0$（$\kappa^{2}=\lambda\sigma^{2}/\eta$）在边界条件 $x(0)=X,\ x(T)=0$ 下的最优轨迹为双曲正弦形式 [[156]][ref156]：

$$x(t)=X\,\frac{\sinh\bigl(\kappa(T-t)\bigr)}{\sinh(\kappa T)}.$$

两个极限：$\lambda=0$（只最小化预期冲击）时轨迹退化为匀速直线，即 TWAP 排程；$\lambda\to\infty$（极度厌恶成本方差）时立即清仓。中间情形越厌恶风险，执行越前置，用更高的即时冲击成本换更短的价格暴露时间 [[156]][ref156]。

```text
示例（数字为假设演示，已复算）：清算 X=100,000 股，期限 T=1 天；
假设日波动 σ=$0.50/股，临时冲击系数 η=1e-6（美元·天/股²），风险厌恶 λ=1e-4。
κ² = λσ²/η = 1e-4 × 0.50² / 1e-6 = 25，κ=5（1/天），κT=5。

剩余持仓比例 x(t)/X = sinh(5(1−t))/sinh(5)，对照 TWAP 的 1−t：
t=0.25：AC 剩余 28.6%（已卖出 71.4%），TWAP 剩余 75.0%（已卖 25%）；
t=0.50：AC 剩余 8.2%，TWAP 剩余 50.0%；
t=0.75：AC 剩余 2.2%，TWAP 剩余 25.0%。

数值积分（步长 1/200000 天）：
AC 临时冲击成本 η∫v²dt ≈ $25,026，成本方差 σ²∫x²dt ≈ 2.50×10⁸；
TWAP 临时冲击成本 = ηX²/T = $10,000，成本方差 = σ²X²T/3 ≈ 8.33×10⁸。
即 AC 以约 2.5 倍的预期冲击成本，把成本方差压到 TWAP 的约 30%。
```

参数看风险厌恶 $\lambda$（在冲击成本与时机风险间定位）、波动 $\sigma$、临时/永久冲击系数 $\eta/\gamma$、期限 $T$、成交量曲线估计（VWAP 用）、子单主动/被动选择。工程上是子单路由与切片、参与率控制、实时剩余持仓与已成交均价跟踪；模型输出排程，成交与延迟假设要在回测里先验过。

什么时候会亏：冲击系数标定失真使前置程度错误；匀速/TWAP 假设在开盘收盘成交量高峰错配；把执行算法的节省误记为策略 alpha；市场急剧变化时静态排程不自适应（Almgren–Chriss 静态解在 ABM 假设下动态最优，换 GBM 或随机波动需重新求解）[[156]][ref156]。

做市（第 4 章）的报价与库存回归是收益策略本身；本节算法只服务于“把一个已决定的大单尽量便宜地执行完”。

## 6. 不同市场的环境与监管约束

同一套策略在不同市场能不能做，先由交易机制（T+0/T+1、有没有做空渠道）、费用结构、报撤单监管与延迟环境决定。这一章按中国大陆证券、中国大陆期货、美国、欧洲、加密五个环境整理公开规则，条文细节以官方现行文本为准。

<a id="hft10-6-1"></a>
### 6.1 中国大陆证券市场（A 股）：程序化报告制度与高频交易认定

证监会《证券市场程序化交易管理规定（试行）》自 2024 年 10 月 8 日起施行，适用于通过计算机程序自动生成或者下达交易指令在证券交易所进行的证券交易 [[69]][ref69]。程序化交易投资者要事先报告账户资金、交易策略类型及主要内容、最高申报速率、单日最高申报笔数、交易软件等信息；高频交易者还要额外报告系统服务器所在地、系统测试报告、故障应急方案 [[69]][ref69]。第二十三条明确，交易所可对高频交易实施差异化收费、适当提高交易收费标准，并可收取撤单费等其他费用，具体标准由交易所规定 [[69]][ref69]。

沪深交易所落地细则把高频交易认定为满足下列任一情形：单个账户每秒申报、撤单的最高笔数达到 300 笔以上，或者单个账户单日申报、撤单的最高笔数达到 20000 笔以上 [[70]][ref70][[71]][ref71]。深交所细则第三十七条规定，交易所可根据申报、撤单的笔数和频率等指标设置收费标准，加收流量费和撤单费，并要求会员把差异化费用成本由高频投资者承担 [[70]][ref70]。行为监控上，细则列出"瞬时申报速率异常"（1 秒钟内申报、撤单笔数达到一定标准）、"频繁瞬时撤单"（日内多次 1 秒内申报又撤单且全日撤单比例达到一定标准）、"频繁拉抬打压""短时间大额成交"等异常交易类型，具体阈值由交易所另行公布并可调整 [[70]][ref70]。

基础交易机制是 T+1、涨跌停、融券限制。回转交易方面，上交所交易规则规定投资者买入的证券在交收前不得卖出，但实行回转交易的除外；股票不在当日回转品种清单内，仅债券 ETF、货币 ETF、黄金 ETF、商品期货 ETF、跨境 ETF、权证等品种实行当日回转，B 股次交易日起回转 [[68]][ref68]。也就是说普通 A 股股票当日买入不能当日卖出（T+1），股票现货侧无法靠日内回转平仓，方向型日内策略在股票现货上不可行。

价格笼子与涨跌幅：主板股票、基金涨跌幅限制比例为 10%，涨跌幅限制价格 = 前收盘价 ×（1 ± 10%）；科创板股票涨跌幅限制为 20%，上市前 5 个交易日不设涨跌幅；连续竞价阶段限价申报还受有效申报价格范围约束（买入不高于买入基准价 102%，卖出不低于卖出基准价 98%）[[68]][ref68]。

做空与融券渠道在 2024 年明显收紧。证监会依法批准中证金融公司自 2024 年 7 月 11 日起暂停转融券业务，存量转融券合约可以展期但不得晚于 9 月 30 日了结 [[72]][ref72]；此前 2024 年 1 月已全面暂停限售股出借，将转融券市场化约定申报由实时可用调整为次日可用，并上调融券保证金比例（一般由不低于 50% 上调至 80%，私募证券投资基金参与融券上调至 100%），同时严禁向利用融券实施日内回转（变相 T+0）的投资者提供融券 [[73]][ref73]。股票现货做空渠道因此收窄，多空对冲类策略主要转向期货、期权。

对策略的含义：A 股股票侧的速度竞争被两道约束压住——一是 T+1 回转限制，二是按笔数收费与重点监控，纯报撤单型做市在股票现货上的单位收益必须覆盖流量费与撤单费成本。

```text
示例（假设费率，仅用于演示算法；现行公开细则未公布统一每笔金额）：
假设某交易所对认定为高频的账户：
- 单日申报+撤单超过 20000 笔的部分，每笔加收流量费 0.10 元；
- 每笔撤单另收撤单费 0.20 元（假设费率，非现行公开标准）。
某账户当日：申报 26000 笔，其中撤单 24000 笔，成交 2000 笔。
超额笔数 = 26000 − 20000 = 6000 笔
流量费     = 6000 × 0.10 = 600 元
撤单费     = 24000 × 0.20 = 4800 元
当日差异化费用合计 = 600 + 4800 = 5400 元
笔数口径报撤成交比（RTS 6 口径：订单数/成交数 − 1）
= 26000 / 2000 − 1 = 12；撤单/成交（直观口径）= 24000 / 2000 = 12 : 1。
```

### 6.2 中国大陆期货市场：报告制度、异常交易监控与差异化收费

证监会《期货市场程序化交易管理规定（试行）》自 2025 年 10 月 9 日起施行，高频交易具体标准由期货交易所制定 [[74]][ref74]。程序化交易者事前报告，高频交易者额外报告交易策略类型及主要内容、最高报撤单频率、单日最高报撤单笔数、服务器所在地、测试报告与应急方案 [[74]][ref74]；第二十六条授权期货交易所建立报撤单收费、交易限额等制度，并可对高频交易手续费实施差异化管理 [[74]][ref74]。

各期货交易所在规则层面对报撤单设有可量化的异常处理标准。以上海期货交易所《异常交易行为管理办法》（2026 年 7 月 6 日起实施）为例，客户或一组实际控制关系账户合并计算后，单个交易日在某一合约上出现下列任一情形即达到处理标准：自成交次数 5 次及以上；撤单次数 500 次及以上；大额撤单（单笔撤单量 300 手及以上）次数 50 次及以上 [[75]][ref75]。处理程序为第一次提示、第二次列入重点关注名单并通报、第三次闭市后限制开仓原则上不少于 1 个月；因套期保值、做市、套利指令产生的相关行为另有豁免 [[75]][ref75]。上期所 2025 年 8 月通知同时规定，1 个交易日内出现 10 次（含）以上"1 秒钟内 10 笔（含）以上报撤单"的交易者，应当履行程序化交易报告义务 [[76]][ref76]。

中金所《程序化交易管理办法》（2025 年 10 月 9 日施行）实行报告、系统接入、主机托管与席位管理；第三十条明确交易所实行报撤单收费、交易限额等制度，并可对高频交易手续费差异化管理；非期货公司会员不得从事高频交易 [[77]][ref77]。

股指期货另有限仓与成本约束。按中金所发〔2022〕73 号通知，自 2022 年 12 月 19 日起，沪深 300、中证 500、中证 1000、上证 50 股指期货上，客户某一合约日内开仓交易最大数量为 500 手，套期保值等风险管理交易不受此限；一组实际控制关系账户合并计算；第一次超限限制开仓 5 个交易日，第二次 10 个交易日，第三次及以上 1 个月 [[78]][ref78]。手续费方面，经证监会同意，自 2023 年 3 月 20 日起四大股指期货各合约平今仓（当日开仓又平仓）交易手续费标准调整为成交金额的万分之二点三 [[79]][ref79]。平今仓高费率直接抬高了当日开平回转策略的成本。

主机托管与席位：期货交易所建立主机托管信息报告制度和交易席位管理制度，遵循安全、公平、合理原则；对频繁异常交易、重大技术故障或违规客户，期货公司不得提供主机托管服务 [[74]][ref74][[77]][ref77]。以中金所为例，会员通过中金所数据有限公司唐镇托管机房申请机柜资源，分为"会员业务发展保障区""会员常态化业务扩容区"等资源分区，按业务发展与扩容条件申请 [[81]][ref81]。与境外商业化 co-location（把服务器机柜放到交易所机房内）不同，境内托管资源由交易所体系分配，且不向客户系统开放交易所系统管理权限 [[77]][ref77]。

<a id="hft10-6-3"></a>
### 6.3 美国市场：Reg NMS、市场准入、Reg SHO 与行情双链路

Reg NMS 于 2005 年通过，包含 Rule 610（市场接入与接入费上限）、Rule 611（订单保护/反 trade-through）、Rule 612（最小报价单位）等 [[82]][ref82]。Rule 611 要求交易中心建立并执行书面政策，防止以劣于其他交易中心已展示"受保护报价"的价格成交（trade-through，即穿过更优报价直接成交）；受保护报价须可即时自动接入且为全国最优买/卖价；最常用的例外是跨市场扫单指令（ISO），扫单同时须把其余 ISO 路由到更优受保护报价的全部展示量 [[82]][ref82]。

接入费与 maker-taker：主流交易所采用 maker-taker 结构——交易所向吃单方（taker）收取接入费，向挂单方（maker）支付返佣，返佣通常由接入费出资，交易所收入为两者之差 [[83]][ref83]。2005 年 Rule 610(c) 对价格 1 美元及以上受保护报价设定的接入费上限为每股 30 mils（即每 100 股 0.30 美元），1 美元以下为报价的 0.3% [[83]][ref83]。SEC 2024 年 9 月通过修订（2024-137），将 1 美元及以上报价的接入费上限降至每股 0.001 美元（10 mils），1 美元以下改为报价的 0.1%，并要求交易所所有费用、返佣在成交时即可确定；Rule 610/612 合规日为 2025 年 11 月首个交易日 [[83]][ref83][[84]][ref84]。SEC 同时指出 maker-taker 会造成展示价与净价不一致、券商为返佣路由产生利益冲突等问题，并存在反向的 taker-maker（向吃单方返佣）结构 [[83]][ref83]。

市场准入规则 Rule 15c3-5 于 2010 年通过，禁止"未过滤"（naked/unfiltered）赞助接入：使用经纪商 MPID（市场参与商标识）接入交易所或 ATS 的客户，其订单必须先经过经纪商的 pre-trade 风控；经纪商须建立财务风控（超过预设信用/资本阈值、明显错误订单不得进入）与监管风控，且风控由经纪商直接、排他控制 [[85]][ref85]。高频商户的前置撤单、价格/数量校验逻辑因此必须落在持牌经纪商链路内。

Reg SHO 管做空，四项核心要求：Rule 200 订单标注 long/short/short-exempt；Rule 201 断路器——个股当日较收盘下跌 10% 及以上后，当日剩余时间及次日只允许以高于全国最优买价的价格卖空（例外除外）；Rule 203(b) 卖空前须完成并记录"locate"（有合理理由相信可借到券）；Rule 204 交收失败须在规定时间内买回或借入平仓，否则触发预借券限制；正常做市豁免 locate 但不免平仓与预借要求 [[86]][ref86]。

行情分发存在两条链路：SIP（Consolidated Tape，联合行情处理器）集中汇集各交易所数据计算 NBBO（全国最优买卖报价）后分发；参与者也可购买各交易所专有直连行情自行聚合 [[43]][ref43]。SEC 指出集中式 SIP 模型相对专有直连存在三类延迟：地理延迟（数据往返各数据中心再回到用户）、聚合延迟（汇总多源并计算 NBBO 的处理时间）、传输延迟（SIP 多走光纤而专有链路可用微波等更快介质）；地理延迟通常是最大项 [[43]][ref43]。延迟敏感的做市与套利普遍订阅专有直连，SIP 仍用于合规校验、LULD 价格带与冗余。IEX 对所有进入订单施加对称的 350 微秒延迟（speed bump，减速带），使挂钩订单在到达撮合引擎前能基于最新行情重定价，并配合 Signal 在报价不稳定时关闭价格裁量，目的是减少延迟套利（latency arbitrage）对被动订单的逆向选择 [[87]][ref87]。

期货市场另有反幌骗条款：Dodd-Frank 第 747 条修订《商品交易法》，7 U.S.C. §6c(a)(5)(C) 将"spoofing"（bidding or offering with the intent to cancel the bid or offer before execution，意图在成交前撤单而报价）列为非法；同条还禁止违反买卖报价与收盘阶段故意/轻率扰乱有序执行 [[88]][ref88]。幌骗、分层只作为合规红线，见第 7 章。

### 6.4 欧洲：MiFID II 框架

MiFID II（Directive 2014/65/EU）第 4(1)(40) 条定义高频算法交易技术，具备三项特征——(a) 用于最小化网络等延迟的基础设施，至少具备 co-location、proximity hosting 或高速直连电子接入之一；(b) 订单发起、生成、路由或执行由系统对每笔交易自动决定、无人工干预；(c) 日内高消息速率（订单、报价、撤单）[[89]][ref89]。第 17 条要求算法交易公司具备弹性系统、交易阈值与限额、防错误订单与业务连续性，向主管机关与交易场所报备，高频公司须按批准格式保存全部挂单（含撤单）记录；以做市为目的的算法交易须在交易场所规定比例的时段持续双边报价并签署书面做市协议；提供直连电子接入的机构须控制系统秩序并限制未成交订单/成交比 [[89]][ref89]。

订单成交比（OTR）：RTS 6（Commission Delegated Regulation (EU) 2017/566）要求交易场所按每个品种、每个成员/参与者计算未成交订单与成交之比，至少在每个交易时段结束时同时给出两个口径——笔数口径（总订单笔数/总成交笔数 − 1）与数量口径（总订单量/总成交量 − 1）；修改单按"撤销+新挂"计 2 笔，双边报价各计 1 笔；超过场所自设最大比值即视为超限，具体阈值由各交易场所自定，欧盟不设统一固定倍数 [[90]][ref90]。

机构组织要求：RTS 9（Commission Delegated Regulation (EU) 2017/589）规定算法交易公司的治理、算法受控部署与测试、盘前/盘中/盘后控制、实时告警，以及第 12 条 kill functionality（紧急情况下可立即撤销任一或全部未成交订单，并能识别每个订单对应的算法、交易台或客户）；高频公司订单记录保存 5 年 [[91]][ref91]。

### 6.5 加密市场环境（背景，独立策略见第 8 章）

API 限频与自成交防护。以币安官方 API 文档为例：现货 REST 按账号计量请求权重（REQUEST_WEIGHT 6000/分钟）与订单数（ORDERS：10 秒 100 笔、单日 200000 笔），超限返回 HTTP 429，持续不后退将升级为 IP 封禁（418）；U 本位期货为请求权重 2400/分钟、订单 1200/分钟 [[92]][ref92][[93]][ref93]。自成交防护（STP）于 2023-01-26 上线，可选模式 NONE / EXPIRE_TAKER / EXPIRE_MAKER / EXPIRE_BOTH，同账号或同 tradeGroupId 的潜在自匹配订单按模式失效，产生 EXPIRED_IN_MATCH 状态与 preventedMatches 记录 [[92]][ref92]。与境内期货交易所"自成交 ≥5 次处理"不同，加密 STP 由下单方自选在匹配前拦截。

## 7. 合规红线：操纵手法的定义、案例与边界

这一章只用于识别违规行为、与合法策略划清界限，不提供任何操作方法。法条（Dodd-Frank 第 747 条 / 7 U.S.C. §6c(a)(5)(C)、Reg SHO 等）见 6.3 与 6.6。

按监管/交易所文件口径，几类手法是：

- 幌骗（spoofing）：提交并非真实意图成交的买/卖报价，意图在成交前撤销，以制造虚假供需印象、诱导他人反应并从中获利 [[95]][ref95][[96]][ref96]。
- 分层（layering）：在一侧多个价位同时挂入大量非真实订单制造供需假象，在人工成交另一侧后随即撤掉这些订单；是幌骗的常见形态 [[96]][ref96][[97]][ref97]。
- 动量点火（momentum ignition）：短时间内连续买卖推动价格到人为水平，引诱他人跟进，再在有利的反向价格成交 [[97]][ref97][[98]][ref98]。
- 报价填充（quote stuffing）：在单只证券上产生极高消息流量（大量高速报撤），FINRA 在 2011 年已把它列为需要评估是否故意操纵的监控对象；多数实例可由算法参数误变解释，但需监督测试与控制 [[98]][ref98]。

公开监管案例有两个常被引用。Navinder Singh Sarao 案：2015-04-21 美国司法部提起刑事控告（1 项电信欺诈、10 项商品欺诈、10 项商品操纵、1 项 spoofing），指控其用自动化程序在 CME E-mini S&P 500 上实施"dynamic layering"，频繁修改并撤掉远离市价的大量卖单，被指与 2010-05-06 Flash Crash 的市场条件相关；Sarao 于 2016 年 11 月就 1 项 spoofing 与 1 项电信欺诈认罪 [[95]][ref95][[96]][ref96][[99]][ref99]。Athena Capital Research 案（SEC 2014-229，SEC 首个 HFT 操纵处罚）：2009 年 6–12 月几乎每个交易日最后 2 秒，用代号 Gravy 的算法对数千只 NASDAQ 股票大举买卖操纵收盘价（marking the close），在受影响股票收盘前几秒占其总成交 70% 以上，支付 100 万美元罚款 [[100]][ref100]。FINRA 监控口径同时覆盖 wash sale、marking the open/close、spoofing、frontrunning 与期权微型操纵 [[98]][ref98]。

供风控/监控理解的识别特征（不是操作指南）：大量挂单在成交前整批撤销，撤单比例与报价档位远离真实成交意图；单侧多层挂单与另一侧真实成交在时间上紧密相邻，成交后非真实单立即消失；短时间内占个股当日（或某分钟窗口）成交比例异常高并伴随显著价格变动，随后反向平仓 [[97]][ref97][[100]][ref100]；单只证券消息速率远超正常做市水平，且与实际成交脱节 [[98]][ref98]。

与合法策略的边界在哪。合法做市也有高撤单率，但每笔挂单有真实成交意图、报价围绕公允价格双侧持续；合法事件/统计策略的订单以自身成交为目的。区分点在于"下单时是否意图成交"以及是否制造虚假供需 [[95]][ref95][[96]][ref96]。美国对 spoofing 同时有刑事（DOJ）与行政（CFTC/SEC）追责，Sarao 为标志性案件 [[95]][ref95][[99]][ref99]；境内程序化交易报告、报撤单收费与异常交易监控阈值见 6.1、6.2，频繁瞬时撤单、拉抬打压属重点监控类型。

## 8. 加密货币市场的高频策略

前面几章讲的做市、套利、统计相对价值和延迟套利，换到加密市场照样成立，但场所和规则变了。加密策略跑在两类地方：中心化交易所（CEX，公司运营、撮合在链下）和链上去中心化交易所（DEX，用智能合约自动撮合）。8.1 到 8.8 讲 CEX，8.9 讲链上 DeFi，8.10 把加密市场和传统市场摆在一起对比，并交代监管差异。

<a id="hft10-8-1"></a>
### 8.1 在 CEX 两边挂单：返佣、负费率与库存

假设你在一个合约对的买一、卖一各挂一张限价单，等别人来成交。你是 maker——先挂单、提供流动性的一方；吃掉你挂单的人是 taker。传统股票市场 maker 也要交一笔正费，加密 CEX 不一样：费率按 maker/taker 分开，高级别账户和签约做市商的 maker 费率可以压到零，甚至为负，也就是每成交一手交易所反过来给你一笔报酬，这笔钱叫返佣（rebate）；taker 费始终为正。于是做市收入拆成两块：买卖价差毛利，加上每笔 maker 成交的返佣净额。

现货普通用户多为双边对称费率（比如 0.10%/0.10%，以交易所官方费率页为准），合约普通用户一般 maker 低于 taker（maker 0.02%、taker 0.05% 这个量级）[[101]][ref101]。VIP 阶梯按近 30 天交易量和资产余额每天重算，级别越高两边费率越低。OKX 官方说明，VIP 用户由 30 天交易量和日资产余额共同分级，普通用户按 OKB 持仓分级，级别每天更新，返佣用和交易费相同的币种支付 [[94]][ref94]。签约做市商另有独立激励计划：Bybit 的 Market Maker Incentive Program 给现货 MM1–MM3 的 maker 返佣 −0.001% 至 −0.0075%，给永续/交割合约 MM1–MM3 的 maker 返佣 −0.0025% 至 −0.0125%，taker 费仍按各自 Pro/VIP 等级；资格按月评估，不达标就取消全部权益 [[102]][ref102]。

加密市场一年 365 天、一天 24 小时不停，没有开盘集合竞价，没有收盘后的价格锚，也没有休市让你慢慢消化手里的库存（做市商自己持有的净多或净空头寸）。库存只能在连续波动里实时对冲或回归中性。

**怎么算这笔净收益。** 单笔 maker 成交的单位净收益：

$$
\text{单位净收益} = \frac{P_{\text{ask}} - P_{\text{bid}}}{P_{\text{mid}}} + r_{\text{maker}} - f_{\text{taker}}^{\text{对冲}}
$$

$r_{\text{maker}}$ 是负费率（返佣，取负值），$f_{\text{taker}}^{\text{对冲}}$ 是主动对冲库存时 taker 腿付的费，用相关合约对冲库存时这笔成本必须算进报价。还有一笔隐性成本叫逆向选择：新信息已经到达，你的旧报价没来得及撤，恰好被信息更足的对手方吃掉，接到的总是坏价格。期望单笔毛利得先盖住逆向选择、库存波动和资金成本，才谈得上赚钱。

```text
示例：负费率下的做市毛利分解（数字仅为手算演示，费率结构以交易所官方页面为准）

假设某合约对合理价 P_mid = 60,000 USDT/币，做市商挂：
  买价 59,970（价差 30 点，即 5 bp）
  卖价 60,030

双边各成交 1 单位，未发生对冲：
  价差毛利 = 60,030 - 59,970 = 60 USDT（每单位合计）

假设该账户为签约 MM，maker 返佣 r_maker = -0.005%（即每单位返佣 3.00 USDT）：
  返佣收入 = 60,000 × 0.00005 = 3.00 USDT

若库存用 taker 腿对冲一次，taker 费 0.05%：
  对冲成本 ≈ 60,000 × 0.0005 = 30 USDT（每腿）
  则 30 点价差 + 3 USDT 返佣可能不足以覆盖对冲费，需要更宽价差或被动平仓。
```

**真做起来看什么。** 挂单深度、队列位置（自己的单子在某价位排队中的顺位）、盘口不平衡（8.7 展开）用来动态调整双边报价宽度；库存偏离目标越多，报价越往促进回归的方向偏，库存过高就压低买价、抬高卖价，或者干脆主动减仓。资金费率的方向和大小（8.2）决定持有永续多/空库存的 carrying cost。MM 计划的流动性考核——最低挂单量、最小挂单时长、盘口覆盖率——是续约硬指标，Bybit 要求衍生品订单规模至少为该合约最小下单量的 10 倍 [[102]][ref102]。

工程上有三件事躲不开。一是撤单竞争：信息到达后，撤单请求必须先于抢单到达撮合引擎生效，剧烈时段行情密度很高，尾部延迟直接决定你暴露在多少逆向选择里。二是多所报价一致：同一基础资产在多个所挂出的报价必须共用同一个估值源，免得一边旧价被吃、另一边已经偏离。三是 7×24 的自动风控：系统故障、行情断线、API 限流都得靠自动撤单、降杠杆、停止报价来处理，不能指望盘中有人工干预。资格保级也要系统持续满足 maker 成交量占比和盘口覆盖率，否则返佣权益失效 [[102]][ref102]。

**什么时候会亏。** 单边成交后市场沿不利方向快速移动，库存浮亏超过价差加返佣，这是逆向选择的直接后果；极端行情下库存对冲不及时可能触发强平，盈利方还可能被自动减仓（8.6）。返佣政策交易所可以单方调整，Bybit 明确保留根据市场条件调整资格标准的权利 [[102]][ref102]。最后是交易所对手方风险：平台暂停提币、停运、冻结账户时，库存和保证金一起被困（8.10）。

机构资料：Bybit 官方 Market Maker Incentive Program 说明 [[102]][ref102]；OKX 官方 Fee Details 与分级规则 [[94]][ref94]；Deribit 官方费率页（期货 maker −0.01% 返佣、taker 0.05%，期权双边 0.03% 标的并封顶期权价 12.5%）[[103]][ref103]。

<a id="hft10-8-2"></a>
### 8.2 永续合约：靠资金费率把价格拽回现货

永续合约（perpetual swap）没有到期日，也就没有到期强制收敛这回事。它靠多头和空头之间定期支付的资金费率（funding rate）把合约价锚回现货指数：费率为正时多头付空头，为负时空头付多头，交易所只撮合双方，不抽这笔钱 [[6]][ref6]。围绕资金费有三类常见做法：买入现货同时卖出等量永续，锁定近似无风险的资金费收入（正向市场、合约溢价、funding 为正时，即 cash-and-carry）；funding 深度为负时反过来，买永续、借币或做空现货收 funding；以及跨所资金费率差，同一标的在 A 所永续付高 funding、在 B 所永续收低 funding，两腿对冲赚净差。

**主流公式长什么样。** BitMEX 风格公式（Binance、Bybit 同构）：

$$
F = P + \operatorname{clamp}(I - P,\, +c,\, -c),\qquad c = 0.05\%
$$

$P$ 是溢价指数（premium index），衡量永续相对指数价的偏离，用冲击边际买卖价相对指数价构造；Bybit 官方定义 $P=[\max(0,\text{Fair Buy}-\text{Index})-\max(0,\text{Index}-\text{Impact Ask})]/\text{Index}$ [[104]][ref104]。$I$ 是利率分量，多数平台每个结算周期给固定小额；He 等在论文中记载的 Binance 参数为 $\iota=0.01\%$、$c=0.05\%$，该数字来自论文转引，正式使用前请以交易所公告为准 [[105]][ref105]。clamp 把 $(I-P)$ 限制在 $\pm 0.05\%$：溢价指数落在利率附近窄带内时，$F$ 被钉在 $I$；只有溢价超出带宽，$F$ 才跟着 $P$ 走。Bybit 每分钟更新一次 $F$，再对分钟序列做 N 小时时间加权平均（TWAP，时间加权平均价）得到结算费率，剧烈波动时平台可临时调整资金费率上下限 [[104]][ref104]。OKX 当前官方公式为 $F=\operatorname{clamp}[\text{MA}(P-I),a,b]$，当前利率分量取 0，溢价指数 $=[(P_{\text{bid}}+P_{\text{ask}})/2-S_{\text{index}}]/S_{\text{index}}$，按结算周期内分钟序列取均值，费率每分钟更新 [[6]][ref6]。

结算间隔并不固定 8 小时。多数主流合约 8 小时结算（00:00/08:00/16:00 UTC），部分合约改成 1/2/4 小时；Binance 对达到上下限的合约会动态把结算频率提到每小时，连续多周期回落到窄带后再降回（结算频率规则经媒体转载，正式使用前请以交易所公告为准）[[106]][ref106]。资金费用的计算很直接：

$$
\text{Funding Fee} = \text{Position Value} \times F
$$

USDT 本位仓位价值 = 标记价 × 合约数量 × 合约面值；币本位仓位价值 = 合约数量 × 合约面值 / 标记价 [[6]][ref6]。He、Manela、Ross、von Wachter 在无摩擦市场推导了永续的无套利价格，并给出含交易成本的边界，实证发现 crypto 永续相对理论价的偏离大于传统货币市场、跨币种同向波动且随时间收敛，构造的隐含套利策略夏普比很高 [[105]][ref105]。Ackerer、Hugonnier、Jermann 给出线性、反向、quanto 永续的显式无套利定价，指出永续价是在反映锚定强度的随机到期时刻现货的风险中性期望 [[107]][ref107]。

![永续资金费率机制与 cash-and-carry 腿图](https://raw.githubusercontent.com/Obscurepawn/TradingSystemLearning/main/hft/assets/hft-10/fig06_funding_carry.png)

*图 7：现货多头与永续空头两腿对冲，资金费在多头与空头之间周期收付，溢价指数在 ±0.05% 带宽内被钉在利率分量、超出带宽后跟随溢价。*

```text
示例：正向 cash-and-carry 的资金费年化（手算演示）

条件：
  现货买入 1 BTC = 60,000 USDT
  永续卖出 1 BTC（等额对冲），当前 funding F = +0.01%/8h
  每日结算 3 次，持有 1 年（365 天）

每 8 小时收到资金费 = 60,000 × 0.0001 = 6.00 USDT
每日收入 = 6.00 × 3 = 18.00 USDT
全年资金费收入 = 18.00 × 365 = 6,570 USDT
相对现货成本的年化 ≈ 6,570 / 60,000 = 10.95%

注意：
1) 这是 funding 不变的静态折算；实际 F 每分钟/每周期重算，会随溢价漂移。
2) 未计买卖价差、taker 费、资金占用与现货/永续基差回归盈亏。
3) 若 F 转负，多头现货+空永续组合改为向空头支付，carry 转为成本。
```

```text
示例：跨所资金费率差（手算演示）

同一 BTC 永续：
  A 所 F_A = +0.10%/8h（多头付空头）
  B 所 F_B = +0.02%/8h

在 A 所开空（收 +0.10%），在 B 所开多（付 +0.02%），两腿名义额相等对冲方向风险：
  每 8h 净收 = 0.10% - 0.02% = 0.08%
  每日净收 ≈ 0.08% × 3 = 0.24%
扣除两所 taker 开仓费与两腿各自保证金占用后才是净利；
若 F_A 收敛到 F_B，价差机会消失，需平仓。
```

```text
示例：同一 0.01% 间隔费率在不同结算间隔下的年化（手算，已复算）。
8h 间隔：0.0001 × 3 × 365 = 10.95%
1h 间隔：0.0001 × 24 × 365 = 87.60%
两所在页面上都显示 0.01%，实际年化相差 8 倍，跨所比较或 OI 加权汇总 funding 时不可直接比每间隔数字 [[140]][ref140]。
```

Coinbase 机构版 Primer 还补了四点值得记住的观察。第一，结算间隔不同时，页面上的 headline funding 必须先统一年化口径，就是上面第三个示例：同样显示 0.01%，8 小时间隔年化 10.95%，1 小时间隔年化 87.6%，直接比数字会错八倍。第二，funding 的正偏是制度性设计，不只是多头情绪：Coinbase 用 CoinMetrics 数据（2022-08-01 至 2024-05-20，逐小时、OI 加权）发现各 CEX 的 BTC funding 超过 85% 的时间为正；正偏既来自多头占优（contango，期货高于现货），也来自 base interest rate 与 clamp 机制本身——溢价落在带宽内时 funding 默认钉在 base rate（常为 10.95% 年化），caps 再把上下限封住，所以“funding 长期为正”不能单独解读成极端拥挤的多头情绪 [[140]][ref140]。第三，funding 是滞后/波动信号，不是价格领先指标：价格上涨先于 funding 上升，动量驱动的交易者顺趋势开多，funding 变化只是市场动量的滞后副产品；持续高 funding 之后可能出现更长的波动期，但反过来不成立，高波动并非总由高 funding 前置 [[140]][ref140]。第四，Coinbase 用 SEC 现货 BTC ETF 审批中对比 CME 期货与现货相关性的同口径方法，发现其永续与现货收益相关性几乎等于 CME 期货与现货相关性，说明 perp 能提供和固定到期期货相近的方向敞口与对冲效用，只是价格锚定机制换成了资金费；另注 Coinbase International 自身采用 1 小时间隔、不设 base rate 与 clamp，各所公式可随市场条件更新 [[140]][ref140]。

**入场前看什么。** 实时/预估 funding、历史 funding 序列、溢价指数 TWAP、结算时刻；两腿仓位价值要匹配（币本位与 U 本位名义额口径不同，见 8.3）；资金费率上下限（cap/floor），达到 cap 会触发结算频率调整 [[106]][ref106]。

**真做起来卡在哪。** 两腿得同时建立，腿风险（一边成交、另一边没成交）让组合短暂裸露方向风险；永续可以即时开仓，现货腿受盘口深度约束。资金费按持仓逐周期收付，在结算时刻之前平仓则不付也不收当期费用（OKX 官方说明）[[6]][ref6]。跨所策略要在两所分别备足保证金，两所之间没有跨所抵押（8.4、8.10）。

**什么时候会亏。** funding 均值回归甚至反转，carry 收益快速缩水或转负；基差风险——现货与永续的价差在平仓前扩大，把资金费收入吃掉；单所永续停盘、保证金规则变更、提币暂停让现货腿撤不出来；动态结算间隔改变时，单位时间资金费和年化折算口径要同步重算。

文献：He, Manela, Ross, von Wachter, *Fundamentals of Perpetual Futures*, arXiv:2212.06888 [[105]][ref105]；Ackerer, Hugonnier, Jermann, *Perpetual Futures Pricing*, arXiv:2310.11771 [[107]][ref107]；Nimmagadda & Ammanamanchi 对 BitMEX 资金费率与 BTC 汇率的 GARCH/Granger 实证，arXiv:1912.03270 [[108]][ref108]；OKX/Bybit 官方资金费说明 [[6]][ref6][[104]][ref104]。

<a id="hft10-8-3"></a>
### 8.3 交割合约基差：年化收益、币本位与 U 本位

交割合约（fixed-maturity futures）有到期日，到期价格收敛现货。基差（basis）= 期货价 − 现货价：期货高于现货叫正向市场（contango），买入现货、卖出期货持有到期兑现基差；期货低于现货叫反向市场（backwardation），方向反过来。和永续 carry 不同，交割合约的收益来自价格收敛，而不是周期资金费，到期前每天都要承担基差波动。

**年化基差怎么算。** 持有至到期近似的年化基差：

$$
\text{年化基差} = \frac{F - S}{S}\times \frac{365}{T}
$$

$F$ 期货价、$S$ 现货价、$T$ 剩余天数。保证金和盈亏的计价方式分两种。U 本位（线性，linear）：保证金与盈亏以 USDT 计价，1 张对应固定币量，盈亏线性 $\text{PnL}_{\text{USDT}} = q\,(P_{\text{exit}} - P_{\text{entry}})$。币本位（反向，inverse）：合约以标的币（如 BTC）计价与结算，盈亏以 BTC 计，同样的美元涨跌在不同价格水平换算成的 BTC 不等，呈非线性。以 XBTUSD 类合约为例，持有 $N$ 张（每张 1 美元名义），以 BTC 计的盈亏：

$$
\text{Long: PnL}_{\text{BTC}} = N\left(\frac{1}{P_{\text{entry}}} - \frac{1}{P_{\text{exit}}}\right),\qquad
\text{Short: PnL}_{\text{BTC}} = N\left(\frac{1}{P_{\text{exit}}} - \frac{1}{P_{\text{entry}}}\right)
$$

（不同平台合约面值与符号约定不同，以官方规则为准。）Alexander、Chen、Imeraj 系统讨论了 Deribit 反向期权/合约的定价与对冲：Deribit 只上市 inverse 产品（不收法币），保证金与结算均以加密货币进行，和 CME 式直接（direct）产品在市场不完全性上不同 [[109]][ref109]。

```text
示例 A：年化基差（手算演示）

现货 S = 60,000 USDT；90 天到期期货 F = 63,000 USDT
毛基差 = 3,000 USDT，相对现货 5%
年化 = 5% × 365/90 = 5% × 4.0556 ≈ 20.3%
扣除借贷成本、交易费与基差波动风险后才是净年化。
```

```text
示例 B：反向（币本位）合约的非线性盈亏（手算演示，空头）

空头 N = 10,000 张（每张 1 USD），开仓 P0 = 60,000
空头 PnL_BTC = N × (1/P_exit - 1/P_entry)

情景 1：跌到 P1 = 55,000（-8.33%），盈利
  PnL_BTC = 10,000 × (1/55,000 - 1/60,000) = +0.01515 BTC
  按出场价折美元 ≈ +0.01515 × 55,000 ≈ +833 USD

情景 2：涨到 P2 = 66,000（+10%），亏损
  PnL_BTC = 10,000 × (1/66,000 - 1/60,000) = -0.01515 BTC
  按出场价折美元 ≈ -0.01515 × 66,000 ≈ -1,000 USD

BTC 盈亏绝对值都是 0.01515，但折成美元后 +833 ≠ -1,000：
同样幅度的价格位移，下跌盈利与上涨亏损的美元价值不对称，
这就是反向合约的非线性（凸性），对冲比例必须按价格动态调整。
```

**看哪些信号。** 各到期月份的基差曲线（近月/季月/半年）、年化基差、持仓量与成交量；借币利率（反向 carry 成本）、交割日、结算参考价；币本位仓位的 BTC 保证金余额与强平价非线性。

**真做起来。** 期现两腿建立与到期平仓都要控制腿风险；交割日前后流动性迁移，提前规划展期；反向合约对冲比例随价格变化，得动态再平衡，不能按固定币量对冲。CME 式受监管比特币/以太期货为现金交割、以参考汇率结算，与 CEX 币本位产品规则不同，具体规格以 CME 官方文件为准。

**什么时候会亏。** 基差不收敛甚至走扩；交割日挤仓；反向合约凸性让固定对冲比例失效，极端价格下保证金被双向侵蚀；现货借币断供、利率飙升。CME 期货受 CFTC 监管、现金交割，属美国境内合规渠道（8.10）。

文献：Alexander, Chen, Imeraj, *Inverse and Quanto Inverse Options in a Black-Scholes World*, arXiv:2107.12041 [[109]][ref109]；Ackerer 等的永续/期货定价框架可对照 [[107]][ref107]。

<a id="hft10-8-4"></a>
### 8.4 跨交易所价差：秒级快套利与跨国慢溢价

同一资产在不同 CEX 的可成交价瞬时偏离，低价所买入、高价所卖出兑现价差。和股票跨所不同，crypto 各所独立撮合，没有统一合并行情（没有 NBBO，即全国最优报价那种统一聚合），没有跨所净额结算，也没有跨所抵押，套利者必须在两所分别备足保证金和现货库存 [[110]][ref110]。

**能不能成交，先看费用边界。** 取 A 所卖一 $A_{\text{ask}}$、B 所买一 $B_{\text{bid}}$，可成交条件：

$$
B_{\text{bid}} - A_{\text{ask}} > f_A + f_B + \text{滑点} + \text{资金/借币成本}
$$

Albers、Cucuringu、Howison、Shestopaloff 用最流动 BTC 市场的秒级以下订单簿与成交数据构造领先—滞后网络，线性模型可解释 500ms 未来收益 10%–37% 的变动，并强调各所费率制度决定其领先/滞后地位；论文还实测了 taker 与实盘 maker 策略（周转 150 万美元名义额）[[110]][ref110]。

```text
示例：跨所价差（手算演示）

A 所卖一 = 60,000，B 所买一 = 60,120，各 1 单位可成交
毛价差 = 120 USDT
假设 taker 费率各 0.05%：
  费用合计 = 60,000×0.0005 + 60,120×0.0005 ≈ 60.06 USDT
净利 ≈ 120 - 60.06 - 滑点，>0 才执行。
若 B 所买一在 A 买单到达前被撤/被吃，只剩 A 腿成交，裸露方向风险。
```

**另一类慢得多的机会：跨国分割下的持续性溢价。** 上面的费用边界处理的是同一资本可自由流动范围内、秒级以内的价差。Makarov 与 Schoar（JFE 2020，样本 2017-01 至 2018-02、19 个国家 34 家交易所 Kaiko tick 数据）记录了另一类持续长得多的偏离 [[139]][ref139]：跨国价格偏离“定期、大规模”出现，常持续数小时，部分情形达数天乃至数周；同一国家内部各所偏离平均通常不超过 1%，跨国偏离大一个数量级。2017-12 至 2018-02 初，美国—韩国每日平均价格比超过 15% 并连续数日达到 40%（Kimchi premium），日本—美国平均约 10%，美国—欧洲约 3%；同口径估算的潜在套利利润（仅取每秒低价区卖发起量与高价区买发起量的较小值），美国—韩国四个月调整后约 12.75 亿美元，美国—日本约 6.75 亿美元，美国—欧洲约 2,500 万美元。偏离高度不对称：美欧之外的国家相对美国几乎只出现溢价、极少折价，各国溢价同时开启、同时收敛（co-movement），并在 BTC 快速上涨期走扩。

关键对照在加密—加密这一层：同期 BTC/ETH 跨币比价在 0.97–1.03 的窄带内，即使韩国法币溢价接近峰值也基本不偏离。也就是说，资本管制约束的是加密—法币兑换与资金跨境回流，而不是加密—加密转换 [[139]][ref139]。套利动作是在低价区（如美国）买入 BTC、在高价区（如韩国）卖出，但利润无法无缝汇回美国时，套利资本“被困”在当地而趋于稀缺，偏离因此无法被抹平。交易成本低、所内流动性充足都不足以解释持续溢价，分割来自法币资本流动管制、结算摩擦与治理风险。这类机会不是本节的秒级延迟套利，而是受跨境资本约束的慢套利，收益兑现周期以天/周计。

```text
示例：跨国溢价为何不会被无成本抹平（说明性假设，非论文数字，Python 已复算）。
美国所 BTC = 60,000 USD；韩国所 BTC = 66,000 USD（10% 溢价）；
双边 taker 费各 0.1%；链上转账/网络费 15 USD；
韩国端 KRW 利润回流美国的兑换/汇出摩擦记为 c（论文只定性描述该约束，不给具体 c）。

毛价差 = 66,000 − 60,000 = 6,000 USD/币
双边 taker 费 = 60,000×0.001 + 66,000×0.001 = 126 USD
链上转账费 = 15 USD

情形 c = 6%：回流成本 = 66,000×0.06 = 3,960 USD
  净利 = 6,000 − 126 − 15 − 3,960 = +1,899 USD（表面可行）
情形 c = 9%：回流成本 = 66,000×0.09 = 5,940 USD
  净利 = 6,000 − 126 − 15 − 5,940 = −81 USD（机会消失）
盈亏平衡回流摩擦 c* = (6,000 − 126 − 15)/66,000 ≈ 8.88%。
结论：是否执行取决于报价差之外的“资金能否自由回流”，当 c 高于盈亏平衡点，
10% 的纸面溢价仍不可套，这正是溢价可持续数天至数周的机制原因。
```

**看什么信号。** 两所最新价、买卖一量、盘口深度、各自标记价/指数价；资金划转到账时间（链上确认数、所内转账）、两所可用库存与保证金；行情传播延迟与两所撮合引擎物理位置。

**真做起来。** 库存预置与再平衡：提币受链上确认时间约束（不同币种确认数不同，交易所还可能临时暂停提币），不能等价差出现才转币，得在两所常驻现货与稳定币库存，定期再平衡。腿风险与单边成交：两所独立成交，先成交一边时必须快速补另一边或用本所对冲。延迟：行情从一所传到另一所、订单到达撮合的时间窗决定机会寿命，Albers 等指出各所服务器位置不同，截面套利可持续的时间至少等于两所间信息传输时间 [[110]][ref110]。托管/co-location（把服务器就近部署到撮合机房）：Deribit 规则书把 HFT 定义为包含“旨在最小化网络延迟的基础设施，至少具备 co-location 或 proximity hosting 之一”、系统自动决策、高消息速率的算法交易 [[111]][ref111]，多数 CEX 不公开 co-location 产品细节。

**什么时候会亏。** 价差在腿完成前消失（报价被撤、被抢）；提币暂停或链上拥堵让库存无法跨所调拨，机会无法复现；交易所宕机（如 2021-05-19 Binance 中断，见 8.6），单边腿无法平仓 [[112]][ref112]；稳定币脱锚让 USDT 计价的“同资产”并不等价（8.10）。跨国溢价另有资金被困风险：高价端卖出所得本币无法合规汇回，套利本金与利润滞留当地，被迫再投资或折价离场；政策突变使回流通道关闭。Makarov–Schoar 样本期为 2017-01 至 2018-02，数字反映当时市场结构，当前各国出入金规则已变化，引用时需注明样本期 [[139]][ref139]。

文献：Albers, Cucuringu, Howison, Shestopaloff, *Fragmentation, Price Formation, and Cross-Impact in Bitcoin Markets*（牛津大学工作论文，含实盘 maker 实验）[[110]][ref110]；Makarov & Schoar, *Trading and Arbitrage in Cryptocurrency Markets*, Journal of Financial Economics 135(2):293–319, 2020（跨国溢价与资本管制）[[139]][ref139]；Deribit 规则书 HFT/co-location 定义 [[111]][ref111]。

### 8.5 同一所内的三角套利

三个交易对（比如 BTC/USDT、ETH/USDT、ETH/BTC）的交叉定价不一致，沿兑换闭环买入卖出兑现价差，这就是三角套利。三条腿都在同一所内成交，没有跨所划转问题，但腿风险和费用边界仍在。

**闭环条件。** 走 $U \to B \to E \to U$（USDT→BTC→ETH→USDT）这个环，可成交条件：

$$
\frac{1}{P_{B/U}^{\text{ask}}}\times P_{E/B}^{\text{bid}}\times P_{E/U}^{\text{bid}} > (1-f)^3
$$

$f$ 是单腿 taker 费率（三腿相同近似），乘积大于 1 再扣除费用为正才有利可图；方向相反的闭环（$U\to E\to B\to U$）用另一组买卖价同样检验。

```text
示例：三角闭环与费用边界（手算演示）

可成交报价：
  BTC/USDT 卖一 P_B/U^ask = 60,000（买 BTC 付 USDT）
  ETH/BTC  买一 P_E/B^bid = 0.0500（卖 BTC 买 ETH）
  ETH/USDT 卖一 P_E/U^bid = 3,050（卖 ETH 收 USDT）

起点 60,000 USDT：
  买 1 BTC；1 BTC 换 1/0.0500 = 20 ETH；20 ETH 卖得 20×3,050 = 61,000 USDT
  毛乘数 = 61,000/60,000 = 1.01667（毛毛利 1.67%）

三腿 taker 费各 f = 0.05%，净乘数 = 1.01667 × (1-0.0005)^3
  (0.9995)^3 ≈ 0.99850
  净乘数 ≈ 1.01667 × 0.99850 ≈ 1.01514 > 1，净额为正。

反例：若毛乘数仅 1.0010，乘 0.99850 ≈ 0.99950 < 1，费用后亏损，不执行。
```

**看什么。** 三个交易对的可成交价与深度、实时交叉汇率隐含价；各对费率（maker/taker 不同，稳定币对费率常更低）；闭环方向与顺序（先买高流动性对还是先买窄价差对，影响腿风险）。

**真做起来。** 三腿得在同一撮合周期内完成，通常用 taker 抢价，费用是主要硬约束；maker 三腿排队则可能只成交部分。实时维护交叉汇率表，机会窗口通常在秒级以内。

**什么时候会亏。** 一腿未成交形成裸露的三角中间库存（比如持有 ETH，既不是多头目标也不是对冲）；同类机器人竞争把毛价差压到费用边界以内；交易对流动性枯竭时滑点超过模型估算。

机制为交易所通用结构，费率边界以各所官方费率页为准 [[94]][ref94][[101]][ref101]。

### 8.6 强平、保险基金与 ADL：只做被动承接，不诱导

极端行情下高杠杆仓位被强制平仓（liquidation），市价单涌入变薄的盘口，形成连环强平，也就是瀑布。合规的短线行为只有一种：强卖压力出清后，被动挂单提供流动性承接价格回归，不预测、不诱导强平。幌骗、分层、制造插针等操纵行为属于合规红线（见合规红线一章），本章不写操作方法。

**先分清三种价格。** 最新价（last price）是最近一笔成交价，用于成交撮合；指数价格（index price）是多所现货加权或中位数参考价，用来防单所插针；标记价格（mark price）在指数价基础上做资金费率调整与基差平滑，用于计算未实现盈亏和触发强平，不一定等于盘口最新成交价。Binance 开发者社区资料给出标记价为多值中位数构造（资金调整指数、基差平滑参考、合约价）的口径 [[113]][ref113]；Deribit 官方：标记价 = 指数价 + 30 秒 EMA(最新价 − 指数)，并对标记价与指数的偏离设带宽（BTC 默认 10%）[[114]][ref114]。

强平仓位先由保险基金（insurance fund，交易所用历史强平盈余积累的承接池）消化；基金不足时触发 ADL（自动减仓，auto-deleveraging）：按盈利比例乘有效杠杆排序，自动平掉对手方最盈利、最高杠杆的仓位来吸收亏损。

```text
示例：强平价与瀑布的量级概念（手算演示，非具体交易所规则）

某 10x 多头，维持保证金率 1%，开仓 P0 = 60,000，保证金 6,000 USDT/币
近似强平价 ≈ 60,000 × (1 - 1/10) = 54,000（未计维持费与资金费）
价格触及 54,000 时代偿系统强制市价卖出；
若盘口深度不足以承接，卖单把价格继续向下一档档打穿，
触发更多账户强平，形成自我强化的瀑布。
```

*图 8：强平瀑布的自我强化循环，保险基金不足时由 ADL 吸收对手方盈利仓位。*

**看什么信号。** 全网未平仓量（OI，open interest）、各杠杆分布、强平价地图（liquidation map）、保险基金余额；标记价相对最新价的偏离、指数价构成与带宽；ADL 排序指标与本账户所处 ADL 队列等级。

**真做起来。** 只做被动承接报价，严格限额与止损；瀑布里流动性撤回速度快，报价必须能秒级撤销。风控依据用标记价而不是最新价，避免被单所瞬时插针误导 [[113]][ref113]。

**两次有公开出处的事件。** 2021-05-19：BTC 当日最大回撤约 33.9%（午夜至 13:09 UTC），Binance 出现交易与 API 中断，散户无法平仓或追加保证金；Baumgartner & Guettler 的 IWH 讨论论文记录了该闪崩、平台中断与保险基金余额变化（前一日 2.904 亿美元、次日 2.887 亿美元），并提出数据回填与保险基金保护的疑点（论文观点，非认定结论）[[112]][ref112]。2025-10-10 至 11：IMF《Crypto Assets Monitor Q1 2026》记载，美国对华关税公告引发风险偏好回落，约 190 亿美元杠杆仓位被自动强平，为 CoinGlass 统计口径下 crypto 史上最大强平事件，自动化强平放大了下跌；报告同时指出极端波动中缺乏熔断机制、流动性持续偏薄 [[115]][ref115]。Bieganowski & Ślepaczuk 把该次闪崩作为自然实验，对比 taker 与 maker 策略在事件中的分化，实证逆向选择与算法交易的系统性风险 [[116]][ref116]。

**什么时候会亏。** 自身承接仓位在二次下杀中被套；ADL 可能平掉自身盈利仓；保险基金穿底后的社会损失机制由全体盈利方承担。

机构资料：IMF Crypto Assets Monitor Q1 2026 [[115]][ref115]；Baumgartner & Guettler, IWH DP 2022-25 [[112]][ref112]；Bieganowski & Ślepaczuk, arXiv:2602.00776 [[116]][ref116]；Deribit 价格口径官方说明 [[114]][ref114]。

<a id="hft10-8-7"></a>
### 8.7 盘口信号在 crypto 市场的实证

盘口和成交事件里藏着短期方向信息：买卖队列失衡、订单流不平衡（OFI，一个窗口内新挂单减撤单减被成交的净方向数量）、撤单与主动成交压力，都能用来做做市价差调整和短方向信号。盘口不平衡的基础算法前面讲过，这里只列 crypto 上的实证。

经典 OFI（Cont, Kukanov, Stoikov）的结论是：短时间内价格变化主要由订单流不平衡驱动，OFI 与价格变化呈线性关系，斜率反比于市场深度；该结论基于美股，crypto 上被多项研究复制检验 [[54]][ref54]。顶层盘口不平衡：

$$
\text{imbalance} = \frac{q_{\text{bid}} - q_{\text{ask}}}{q_{\text{bid}} + q_{\text{ask}}}
$$

```text
示例：盘口不平衡读数（手算演示）

买一 900 单位、卖一 100 单位：
  imbalance = (900-100)/(900+100) = 0.80
表示买方挂单占绝对多数；但挂单可撤，需结合主动成交与撤单流判断。
```

**实证发现。** Koutmos 用 2013–2023 年数据发现订单流不平衡 Granger 引起收益的频率高于反向，可用于 nowcasting BTC 崩盘风险，但极端下跌常伴随不显著的不平衡，线性模型不足 [[117]][ref117]。信号衰减很快，需要低延迟重建本地账本。深度学习方向：Wang 在 Bybit 公开 BTC/USDT LOB 快照（100ms–多秒间隔）上对比逻辑回归、XGBoost、DeepLOB、Conv1D+LSTM，发现数据预处理与特征工程的贡献大于堆叠网络层数，简单模型经调参可匹配甚至超过复杂网络，且推理更快、可解释性更强 [[118]][ref118]；Bieganowski & Ślepaczuk 在 Binance 期货 1 秒频率数据（2022-01 至 2025-10，多资产）上用 CatBoost + SHAP 得到跨资产稳定的特征排序（OFI、价差、逆向选择），并以 taker/maker 回测验证可交易性 [[116]][ref116]。

**什么时候会失效。** 噪声大，信号在费用之外没有正期望；训练样本过拟合；结构突变（制度变更、新交易所上线）让特征失效。信号使用本身不违规，但配合抢跑或操纵就越界。

文献：Cont, Kukanov, Stoikov, *The Price Impact of Order Book Events*, arXiv:1011.6402 [[54]][ref54]；Wang, arXiv:2506.05764 [[118]][ref118]；Bieganowski & Ślepaczuk, arXiv:2602.00776 [[116]][ref116]；Koutmos, *Nowcasting bitcoin's crash risk with order imbalance*, Rev Quant Finan Acc 2023 [[117]][ref117]；Albers 等跨所领先—滞后实证 [[110]][ref110]。

### 8.8 Deribit 期权做市：报价、Delta 对冲与 MMP

Deribit 占据 crypto 期权绝大部分成交量，Alexander 等记载超过 90% 的交易所期权交易在 Deribit [[109]][ref109]。做市商对期权双边报价赚价差，同时用永续/期货做 Delta 对冲——Delta 是期权价对标的价格的敏感度，卖出看涨后买入 $\Delta$ 份标的，抵消小幅标的价格对组合的一阶影响；此外还要管理 Vega（对隐含波动率的敏感度）、Gamma（Delta 自身的变化率）与时间价值。

**币本位期权怎么结算。** Premium 以 BTC 报价、以 BTC 结算，期权费与保证金均为 BTC；Deribit BTC 期权 1 张对应 1 BTC，结算为现金（币）结算，到期价为 Deribit 指数到期前 30 分钟时间加权平均（4 秒一次采样，共 450 个样本）[[114]][ref114][[109]][ref109]。MMP（Market Maker Protection，做市商保护）是 Deribit 规则书定义的自动撤回报价机制：当 Delta 或数量计数器达到/超过阈值时触发，只撤销标记为 MMP 的订单；MMP 需向交易所申请，由交易所自行决定是否开通 [[111]][ref111]。

```text
示例：Deribit 期权费计算（官方示例改写，出自 Deribit 费率页）[[103]][ref103]

BTC 期权成交价 0.008 BTC，数量 3：
  费率 = MIN(0.0003 BTC, 0.125 × 期权价) × 数量
       = MIN(0.0003, 0.125×0.008=0.001) × 3
       = 0.0003 × 3 = 0.0009 BTC
（maker 与 taker 同费率，与股票式 maker/taker 不对称不同。）

期货/永续：BTC 期货 maker 0.00%、taker 0.05%；
周度期货 maker 为 -0.01% 返佣、taker 0.05% [[103]][ref103]。
```

**看什么。** 隐含波动率曲面（行权价×期限）、Delta、Vega、Gamma、Theta；永续/期货对冲腿的 basis 与 funding；MMP 的 Delta 阈值、数量阈值、冻结时长配置；到期结算 TWAP 窗口与指数构成（Bitstamp、Coinbase、Kraken、LMAX Digital 等等权，偏离中位数 ±0.5% 被调整）[[114]][ref114]。

**真做起来。** Delta 对冲高频执行，对冲腿多为 taker，成本计入报价；Gamma 大的近月短持仓位需要反复再平衡；MMP 在系统或模型异常时自动撤单，避免失控报价继续成交 [[111]][ref111]；币本位下保证金价值随 BTC 价格波动，风险预算要按 BTC 计价单独管理。

**什么时候会亏。** 波动率突变使 Vega 裸奔；Gamma 挤压下对冲追涨杀跌；到期前 TWAP 操纵嫌疑与结算窗口波动；流动性在深度虚值合约上很薄；反向期权的非线性定价误差（8.3、[[109]][ref109]）。Deribit 受 VARA 监管（迪拜），其他 crypto 期权平台补充；美国境内通过受监管渠道交易（8.10）。

机构/文献：Deribit 规则书（MMP）[[111]][ref111]、费率页 [[103]][ref103]、价格计算页 [[114]][ref114]；Alexander, Chen, Imeraj 反向期权定价 [[109]][ref109]。

### 8.9 链上/DeFi：AMM 边界、LVR 与 MEV

链上高频在公开 mempool（待打包交易池）和区块内竞争机会：DEX 与 CEX 价差套利、清算借贷抵押品。三明治攻击和抢跑只作为风险与合规对象说明，本节不写任何攻击操作教程。

**常数乘积池怎么报价。** AMM（自动做市商）不用订单簿，靠公式报价。池内储备 $x$（计价币）、$y$（基础币）满足不变量 $xy=k$。交易者投入 $\Delta x$，扣除比例费 $(1-\gamma)$ 后实际进入池的为 $\gamma\Delta x$，收到：

$$
\Delta y = y - \frac{k}{x + \gamma\Delta x}
$$

Uniswap v2 每笔 swap 费 0.30%（γ=0.997），其中 0.25% 归 LP（流动性提供者）、0.05% 为可开关协议费（ethereum.org 注解教程记载）[[119]][ref119]。

**含费无套利区间。** 从池买入基础币的边际价为 $P_{\text{pool}}/\gamma$，向池卖出基础币的边际价为 $\gamma P_{\text{pool}}$；外部参考价 $P_{\text{ext}}$ 只有满足 $P_{\text{ext}} > P_{\text{pool}}/\gamma$（外部更贵，可买池卖外）或 $P_{\text{ext}} < \gamma P_{\text{pool}}$（外部更便宜，可买外卖池）时才有扣费后的套利空间，近似边界 $[\gamma P_{\text{ext}},\, P_{\text{ext}}/\gamma]$（精确边界由不变量与费用联立求解，Angeris 等给出常数乘积市场紧跟参考价的正式条件）[[120]][ref120]。

![AMM 含费无套利带宽：外部参考价落在 γP 到 P/γ 区间内时套利者扣费后无利可图](https://raw.githubusercontent.com/Obscurepawn/TradingSystemLearning/main/hft/assets/hft-10/fig07_amm_arb_band.png)

*图 9：常数乘积池的含费无套利带宽 $[\gamma P,\, P/\gamma]$，池价可在带内自由漂移而不触发套利。*

**LP 为什么结构性亏钱：LVR。** Milionis、Moallemi、Roughgarden、Zhang 证明 LP 回报分解为市场风险 beta 项加微观结构 alpha 项（手续费收入减被套利者拿走的损失）。LVR（loss-versus-rebalancing，损失 vs 再平衡）就是被动做市相对被动盯市组合的系统性损耗。常数乘积（θ=1/2）下瞬时 LVR 率：

$$
\ell(\sigma,P) = \frac{L\sigma^2}{4}\sqrt{P},\qquad \frac{\ell(\sigma,P)}{V(P)} = \frac{\sigma^2}{8}
$$

单位池价值的 LVR 损耗率为瞬时方差的 1/8；论文自算示例：ETH 日波动 σ=5% 时，LP 每日约损失 $\sigma^2/8=3.125$ bp 池价值给 LVR [[121]][ref121]。

**MEV 是什么。** MEV（最大可提取价值）是在区块内重排、插入、抢跑交易所能额外拿到的利润，可以理解成传统市场抢跑在链上的对应物。Daian 等《Flash Boys 2.0》在 2019 年量化了 DEX 套利机器人的抢跑、优先燃气拍卖（PGA，按出价高低决定打包顺序），提出 MEV（当时称 miner extractable value）概念，并指出高优先费对共识层的系统性风险 [[122]][ref122]。

```text
示例 A：x·y=k 与含费无套利带宽（手算演示）

池：x = 100,000 USDC，y = 20 WETH，k = 2,000,000
池价 P0 = x/y = 5,000 USDC/ETH，γ = 0.997（0.3% 费）

带宽边界：
  下界 = γ × P0 = 0.997 × 5,000 = 4,985.0
  上界 = P0 / γ = 5,000 / 0.997 ≈ 5,015.05
外部参考价落在 (4,985.0, 5,015.05) 内时，套利者扣费后无利可图，池价可在带内漂移。

示例 B：小额换入（手算演示）
投入 Δx = 1,000 USDC，实际入池 γΔx = 997：
  Δy = 20 - 2,000,000/(100,000+997) = 20 - 19.8026 ≈ 0.1974 ETH
  含费均价 ≈ 1,000/0.1974 ≈ 5,066 USDC/ETH，劣于池价 5,000。

示例 C：LVR 日损耗（论文示例）[[121]][ref121]
σ = 5%/日：σ²/8 = 0.0025/8 = 0.0003125 = 3.125 bp/日。
```

![MEV/PBS 流程：公开 mempool、私有 Protect、MEV-Share 输入 → 搜索者 bundle → relay → 构建者竞价 → MEV-Boost → 验证者提议区块](https://raw.githubusercontent.com/Obscurepawn/TradingSystemLearning/main/hft/assets/hft-10/fig08_mev_pipeline.png)

*图 10：以太坊 PBS/MEV-Boost 的区块空间竞价流程，EIP-1559 base fee 销毁、验证者仅收 priority fee。*

**排序层怎么组织。** PBS（提议者—构建者分离）把建块与提议分开：以太坊合并后，构建者竞价出售区块空间，验证者只挑最高出价的负载；MEV-Boost 是 Flashbots 为 PoS 以太坊实现的开源离链 PBS，验证者向开放构建者市场出售区块空间 [[123]][ref123][[124]][ref124]。私有订单流：Flashbots Protect 把交易送入私有 Flashbots mempool，隐藏于抢跑/三明治机器人之外，并提供 MEV 与 gas 返还；MEV-Share 允许选择性共享交易信息以分成返还 [[125]][ref125]。EIP-1559：每块 base fee（基础费）按上块用量动态调整并销毁，验证者只收 priority fee（优先费），套利竞价在 priority fee 层面展开 [[126]][ref126]。L2 排序器（sequencer，链下层二负责对用户交易排序并提交上链的组件）：以 Arbitrum 官方文档为例，单一 Sequencer 接收、排队并排序交易，无公开 mempool；排序策略三选一——FCFS（按到达时间，新链默认）、PGA（按 priority fee，Arbitrum One 当前采用）、Timeboost（拍卖快速通道，其余 FCFS）；PGA 每轮按 priority fee 提升等待队列，平局按到达时间，并有抗饥饿加成 [[127]][ref127]。其他乐观 L2（Optimism、Base）采用单排序器模式，规则以各自官方文档为准。

**看什么。** CEX 最新价对比多池储备价、gas 价格、区块时间、待打包交易（公开 mempool 可见部分）；LVR 与手续费收入的平衡：对冲后 LP P&L ≈ 费收入 − LVR [[121]][ref121]；清算机会看抵押率阈值、借贷池健康因子；三明治/抢跑仅作为风险与合规对象说明，不提供方法 [[122]][ref122]。

**什么时候会亏。** 交易在打包前被复制/抢跑（公开 mempool 暴露）；回滚与无效交易成本；智能合约风险：池被操纵、预言机错误、清算合约漏洞；LVR 使被动 LP 结构性亏损，对冲只能转移市场风险、不能消除 LVR [[121]][ref121]；排序器中心化/审查风险、PGA 费用军备竞赛 [[122]][ref122][[127]][ref127]。MEV 相关实践在各辖区法律地位不同，攻击型 MEV（三明治、抢跑）可能构成市场操纵或欺诈。

文献：Milionis 等 LVR, arXiv:2208.06046 [[121]][ref121]；Angeris 等 Uniswap 市场分析, arXiv:1911.03380 [[120]][ref120]；Daian 等 Flash Boys 2.0, arXiv:1904.05234 [[122]][ref122]；ethereum.org MEV 文档 [[124]][ref124]；Flashbots Protect/MEV-Share [[125]][ref125]；MEV-Boost [[123]][ref123]；EIP-1559 [[126]][ref126]；Arbitrum Sequencer 文档 [[127]][ref127]；ethereum.org Uniswap v2 注解 [[119]][ref119]。

## 9. 策略收益来源的验证（研究与回测口径）

回测里年化 40% 的库存做市策略，纸面夏普漂亮得很，真钱一上却开始亏钱。这种落差通常不是信号突然失效，而是回测在三件事上替你省了麻烦：假设你的挂单总能轮到成交，假设你看到的信息就是当时全部的信息，最后结账时又把同一笔成本扣了两遍。这一章不讲新策略，只回答一个问题：回测出的收益，到底是策略自己赚的，还是假设送的。

### 先用对尺子：每类策略该量什么

不同策略的利润机制不一样，最小研究对象和关键对照也不该用同一把尺子。做市要看逐笔成交后的价格走向（markout：被动成交之后，中间价朝有利还是不利方向走一段，用来区分"被好价格成交"和"来不及撤单接住坏价格"）；预测类信号要看成交后净收益随时间怎么衰减；套利类要看完整复制成本，而不是只看中间价信号。下表把各类策略的最小研究对象、关键对照和主要评价量并列出来。

| 策略 | 最小研究对象 | 关键对照 | 主要评价量 |
|---|---|---|---|
| 期现、ETF 套利（第 2、5.2 节） | 可成交篮子、期货/ETF、融资与申赎现金流 | 中间价信号 vs 完整复制成本 | 完整组合净收益、未完成腿敞口、资金占用 |
| 跨期套利（第 3 章） | 两个月份合约与原生价差簿 | 原生组合执行 vs 拆腿执行 | 净价差收益、修复成本、期限风险 |
| 库存做市（第 4 章） | 逐笔盘口、队列、委托与成交回报 | 固定报价、库存偏移、加入预测三档对照 | 成交后 markout、净收益、库存分布与尾部损失 |
| 短期预测/OFI/lead-lag（5.4、5.5） | 本地可见特征与未来标签 | 无条件基线、简单线性模型、复杂模型 | 成交后净收益、信号衰减曲线、容量 |
| 延迟/跨所套利（5.1、8.4） | 多场所时间线、成功与失败请求 | 观察到的机会 vs 真正完成的组合 | 捕获率、单腿亏损、再平衡成本 |
| 期权策略（4.5、5.9） | 合约簿、波动率曲面、Greeks 与对冲成交 | 不同对冲频率与组合限额 | 对冲后损益、Greeks 暴露、跳跃损失 |
| 集合竞价承接（5.10） | NOII/虚拟行情序列、获配回报、隔夜库存 | 不参与 vs 参与、不同申报价 | 竞价改善、获配比例、隔夜库存净损益 |
| 执行算法（5.11） | 子单成交与基准价序列 | TWAP/VWAP/到达价基准 | 基准达成差、冲击成本、成本方差 |

### 成交这一笔，回测替你假设了多少

历史最新价扫到你的挂单价，不等于轮到你。你在这一档排队的顺位（队列位置）可能还没排到，前方队列尚未耗尽；盘口数量减少，也可能来自你后方的人撤单，跟你前面有没有人无关。行情回放式回测（hftbacktest 即此类）明确声明：自己的订单不改变模拟市场、不考虑市场冲击，因此只适用于订单小到不起波澜的假设。它提供两类队列假设：最保守的 RiskAverseQueueModel 把撤改只放在队尾，队列位置只在该价位真实成交时才前进；ProbQueueModel 按当前队列位置做概率推进，撤改可发生在前方或后方 [[158]][ref158]。主动吃单（taker）在回放里也按最佳价全部成交，单量大时同样失真。选哪一种成交与队列假设，直接决定回测成交率，不能默认挑最乐观的那个。

### 你是在哪个时刻"看到"这件事的

行情送到本地、订单进入撮合、响应返回，是三段不同的延迟。订单已经成交而本地回报还没到时，真实库存和策略账上的库存并不一致；撤单刚刚发出，仍可能输给到达更早的主动订单。把延迟拆开：feed latency 是交易所发出行情到本地收到的间隔，order entry latency 是发请求到撮合引擎处理的间隔，order response latency 是撮合处理完到本地收到回报的间隔，成交回报也受最后这段影响。模型形式有常数、用实测往返样本插值（定期提交不可成交的空单采集真实数据），以及由行情延迟派生三类 [[159]][ref159]。每条行情带交易所时间戳和本地时间戳两条记录，模拟时分别排序，策略只能使用已经送达本地的消息；让它提前读到还没回报的成交状态，就是前视偏差。

### 净收益这笔账，别重复扣也别漏

每条腿分别记录数量、实际成交价、手续费、返佣，再加上融资、借券、申赎与资金支付；期末未平仓按同一个价格口径估值，另报实际清算成本。价差收益、逆向选择、滑点这些词用来解释损益从哪来；某项影响如果已经体现在实际成交价里，就不能再作为成本扣一次。对账的最小单位是一笔逻辑订单：挂单前的盘口、发送记录、接受或撤改结果、全部成交回报、后续价格串成一条线，才能逐笔追问"这笔为什么成交"。

### 训练和测试不能偷看彼此

训练、验证、样本外按时间先后划分，冻结区间看过结果后不得再回头调参。金融标签常由一段未来收益构成（如三屏障标签），相邻样本的标签在时间上重叠，随机 k 折会让同一段未来价格同时进入训练集和测试集，泄漏就这么发生。López de Prado 给出两个处理：purging 清除训练集中标签区间与测试集标签区间重叠的样本；embargo 在测试块之后再剔除一小段紧邻训练样本，缓冲 h≈0.01T，挡住序列相关特征携带过来的测试期信息；更进一步可用组合净化交叉验证（CPCV）生成多条回测路径，得到夏普比的分布，而不是孤零零一个估计值 [[157]][ref157]。

### 规模上去之后，收益还剩多少

增加挂单数量会压低成交质量，扩大套利规模会自己吃掉全部价差；几个看似独立的策略，可能在同时消耗同一笔现金或同一档深度。报告平均净收益的同时，还要保留部分成交后的最大敞口、资金峰值、库存尾部、最差事件与按交易日计算的回撤。
